# Программирование на 1С:Элемент — курс с нуля

Учебный курс по программированию на платформе **1С:Предприятие.Элемент**
(облачная среда «Элемент Скрипт»). Курс рассчитан на полное знакомство
с языком **с нуля**: предварительные знания в программировании не нужны.

Программируем прямо в браузере — ничего устанавливать не требуется.

## Что внутри

На каждый урок есть три материала — как в нашем курсе по C++:

| Материал | Файл | Для кого |
|----------|------|----------|
| **Презентация** | `prezentaciya.md` | показывается на экране во время урока |
| **Рабочий лист** | `rabochiy-list.md` | раздаётся ученику: задания и место для кода |
| **Решения** | `resheniya.md` | только для преподавателя: ответы и разбор |

Презентации написаны в формате [Marp](https://marp.app/): это обычный
Markdown, который одной командой превращается в слайды (PDF / PPTX / HTML).
Можно и просто читать как текст.

## Структура репозитория

```
README.md                     — этот файл
docs/
  programma-kursa.md          — полная программа всех уроков
  spravochnik-sintaksis.md    — шпаргалка по языку 1С:Элемент
  metodichka.md               — методические указания для преподавателя
uroki/
  urok-01-znakomstvo/
    prezentaciya.md
    rabochiy-list.md
    resheniya.md
  urok-02-peremennye/
    ...
```

## С чего начать преподавателю

1. Прочитать `docs/programma-kursa.md` — общая логика и траектория.
2. Открыть `docs/metodichka.md` — как вести занятия, тайминг, типичные ошибки.
3. Под рукой держать `docs/spravochnik-sintaksis.md` — вся нужная справка
   по синтаксису на одной странице.

## С чего начать ученику

Открыть среду «1С:Предприятие.Элемент Скрипт» в браузере, создать новый
скрипт и написать первый `метод Скрипт()`. Всё остальное — на уроке 1.

## Как собрать презентации в слайды (необязательно)

```bash
# установить marp-cli (один раз)
npm install -g @marp-team/marp-cli

# собрать один урок в PDF
marp uroki/urok-01-znakomstvo/prezentaciya.md --pdf
```
