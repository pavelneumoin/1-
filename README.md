# Программирование на 1С:Элемент — курс с нуля

Учебный курс по программированию на платформе **1С:Предприятие.Элемент**
(облачная среда «Элемент Скрипт»). Курс рассчитан на полное знакомство
с языком **с нуля**: предварительные знания в программировании не нужны.

Программируем прямо в браузере — ничего устанавливать не требуется.

## Готовность курса

| Модуль | Уроки | Статус |
|--------|-------|--------|
| 1. Первые шаги | 1–6 | ✅ готовы (презентация+PDF, классная и домашняя работа, решения) |
| 2. Повторения и данные | 7. Цикл «Пока» · 8. Цикл «Для» | ✅ готовы |
| 2. Повторения и данные | 11. Проект «Викторина-тренажёр» | ✅ готов (на циклах и условиях, без массивов) |
| 2. Повторения и данные | 9–10 (массивы, перебор «для каждого») | ⏸ ждут уточнения синтаксиса коллекций в среде |
| 3–5 | 12–24 | 📋 запланированы (см. `docs/programma-kursa.md`) |

> Уроки 9–10 про массивы намеренно не выпущены: точная запись создания
> коллекций в 1С:Элемент должна быть сверена с живой средой (документация
> вендора недоступна из этого окружения). Как только появится один реальный
> пример (создание массива + перебор) — эти два урока будут готовы быстро.

> **Про синтаксис.** Материалы написаны по официальной документации языка
> 1С:Элемент. Несколько прикладных деталей (оператор остатка `%`, функция
> целой части `Цел`, точная форма заголовка цикла «Для» и работа с
> коллекциями) могут немного отличаться в конкретной версии среды — такие
> места явно помечены в решениях для преподавателя с советом свериться с
> автодополнением. Базовые конструкции (вывод, переменные, условия,
> цикл «Пока») одинаковы везде.

## Что внутри

На каждый урок есть три материала — как в нашем курсе по C++:

| Материал | Файл | Для кого |
|----------|------|----------|
| **Презентация** | `prezentaciya.md` | показывается на экране во время урока |
| **Рабочий лист (класс)** | `rabochiy-list.md` | работа на уроке: задания, блиц-практика, место для кода |
| **Домашняя работа** | `domashnyaya-rabota.md` | большой набор задач на дом (части А / Б / В) |
| **Решения** | `resheniya.md` | только для преподавателя: ответы на классную и домашнюю работу |

> Практики специально много: программирование осваивается только через
> регулярное письмо кода. В классе — задания + «блиц», дома — отдельный
> лист с десятком задач по нарастающей сложности.

Презентации написаны в Markdown (формат, совместимый с [Marp](https://marp.app/):
слайды разделены строкой `---`). Их можно читать как текст, а можно собрать
в **красивый PDF** одной командой — см. ниже. Готовые PDF лежат рядом с
каждым `prezentaciya.md`.

## С чего начать преподавателю

1. Прочитать `docs/programma-kursa.md` — общая логика и траектория.
2. Открыть `docs/metodichka.md` — как вести занятия, тайминг, типичные ошибки.
3. Под рукой держать `docs/spravochnik-sintaksis.md` — вся нужная справка
   по синтаксису на одной странице.

## С чего начать ученику

Открыть среду «1С:Предприятие.Элемент Скрипт» в браузере, создать новый
скрипт и написать первый `метод Скрипт()`. Всё остальное — на уроке 1.

## Как собрать презентации в PDF

В репозитории есть свой сборщик `tools/build_pdf.py` — он превращает
Markdown-презентации в яркие детские слайды и рендерит PDF **без браузера**
(через WeasyPrint), что удобно для серверов и облачных окружений.

```bash
# установить зависимости (один раз)
pip3 install weasyprint markdown pygments

# собрать ВСЕ презентации курса
python3 tools/build_pdf.py

# собрать только один урок
python3 tools/build_pdf.py uroki/urok-01-znakomstvo/prezentaciya.md
```

Рабочие листы и листы домашней работы собираются отдельным сборщиком
(формат A4, под печать, с полями для записи кода):

```bash
# собрать ВСЕ рабочие листы и домашки
python3 tools/build_worksheets.py

# собрать один лист
python3 tools/build_worksheets.py uroki/urok-01-znakomstvo/rabochiy-list.md
```

Оформление листов — в `tools/worksheet.css`.

PDF появится рядом с исходником: `uroki/.../prezentaciya.pdf`.
Оформление слайдов задаётся в `tools/theme.css` — цвета и шрифты можно
менять под свой вкус.

### Как размечать слайды (для авторов)

Слайды разделяются строкой `---`. В начале слайда можно поставить директивы:

```
<!-- kicker: ВЫВОД -->        метка-рубрика над заголовком
<!-- class: quiz -->          тип слайда: quiz / section / tight ...
```

Блоки кода размечаются языком, чтобы получить нужное оформление:

- <code>```eos</code> — код на 1С:Элемент, рисуется как **редактор** с подсветкой;
- <code>```out</code> — вывод программы, рисуется как **терминал**;
- без языка — простая тёмная плашка.

Акцент-карточки внутри слайда (живость урока):

```
<div class="callout tip"><span class="lead">Совет</span>
Текст совета…</div>
```

Доступные виды карточек: `tip` (зелёная), `warn` (красная),
`quiz` (фиолетовая), `fun` (жёлтая) и без класса (нейтральная).
