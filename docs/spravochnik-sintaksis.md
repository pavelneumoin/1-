# Шпаргалка по языку 1С:Элемент

Краткий справочник по синтаксису языка **1С:Элемент** (среда «Элемент Скрипт»).
Держите эту страницу под рукой на каждом уроке.

> Ключевые слова в языке пишутся **строчными буквами**: `пер`, `знч`,
> `метод`, `если`, `иначе`, `для`, `пока`, `возврат` и т. д.

---

## 1. Точка входа

Любой скрипт начинает выполняться с метода с именем `Скрипт`:

```
метод Скрипт()
    Консоль.Записать("Привет, мир!")
;
```

Каждый блок (метод, условие, цикл) **закрывается точкой с запятой `;`** —
никаких `КонецЕсли`, `КонецЦикла`, фигурных скобок `{}`.

---

## 2. Вывод и ввод

```
Консоль.Записать("текст")              // вывести строку
Консоль.Записать(Число)                // вывести значение переменной

пер Имя = Консоль.СчитатьСтроку("Введите имя: ")   // прочитать строку
пер Возраст = Консоль.СчитатьЧисло("Возраст: ")    // прочитать число
```

---

## 3. Переменные и константы

```
пер Счёт: Число = 0          // изменяемая переменная (можно менять)
знч Пи: Число = 3.14         // константа (изменить нельзя)

пер Имя = "Аня"              // тип можно не писать — он определится сам
Счёт = Счёт + 1              // присваивание нового значения
```

- `пер` — переменная, значение можно менять.
- `знч` — значение-константа, менять нельзя.
- Тип указывается **через двоеточие** после имени: `пер x: Число`.

---

## 4. Основные типы данных

| Тип | Что хранит | Примеры значений |
|-----|------------|------------------|
| `Строка` | текст | `"Привет"`, `"42"`, `""` |
| `Число` | числа | `0`, `-7`, `3.14` |
| `Булево` | да/нет | `Истина`, `Ложь` |

Составной тип (несколько вариантов) записывается через `|`:

```
пер Ответ: Строка|Число = 0
```

---

## 5. Строки

```
пер Имя = "Мир"
Консоль.Записать("Привет, " + Имя + "!")   // склейка через +
Консоль.Записать("Привет, $Имя!")          // подстановка через $Имя
```

`$Имя` внутри строки подставляет значение переменной — это **интерполяция**.

---

## 6. Арифметика

```
+   сложение            5 + 3   → 8
-   вычитание           5 - 3   → 2
*   умножение           5 * 3   → 15
/   деление             7 / 2   → 3.5
```

Порядок действий — как в математике, скобки `( )` меняют приоритет.

---

## 7. Сравнения и логика

```
=    равно              a = b
<>   не равно           a <> b
>    больше             a > b
<    меньше             a < b
>=   больше или равно   a >= b
<=   меньше или равно   a <= b
```

Логические операции: `и`, `или`, `не`.

```
если Возраст >= 7 и Возраст <= 17 тогда ...
```

---

## 8. Условия

```
если Оценка >= 5 тогда
    Консоль.Записать("Отлично")
иначеесли Оценка >= 3 тогда
    Консоль.Записать("Сдано")
иначе
    Консоль.Записать("Пересдача")
;
```

---

## 9. Циклы

**Пока** — повторять, пока условие истинно:

```
пер i: Число = 1
пока i <= 5 цикл
    Консоль.Записать(i)
    i = i + 1
;
```

**Для** — повторять заданное число раз (счётчик идёт от и до):

```
для i = 1 по 5 цикл
    Консоль.Записать(i)
;
```

**Для каждого** — пройти по всем элементам коллекции:

```
для каждого Элемент из Коллекция цикл
    Консоль.Записать(Элемент)
;
```

> Платформа развивается, и точная форма заголовка цикла «Для» и работа с
> коллекциями (как создаётся массив/список) могут немного отличаться в вашей
> версии среды. Если среда подсветит ошибку — посмотрите подсказку
> автодополнения: смысл конструкций тот же, меняется только запись.

---

## 10. Методы (функции и процедуры)

В языке нет отдельных «функций» и «процедур» — есть один **метод**.
Если у метода указан возвращаемый тип — он возвращает значение (функция),
если не указан — просто выполняет действия (процедура).

```
// метод, который возвращает Число
метод Сумма(А: Число, Б: Число): Число
    возврат А + Б
;

// метод без возвращаемого значения
метод Поздороваться(Имя: Строка)
    Консоль.Записать("Привет, $Имя!")
;

метод Скрипт()
    пер Результат = Сумма(3, 5)
    Консоль.Записать("3 + 5 = $Результат")
    Поздороваться("Мир")
;
```

## Мини-словарик ключевых слов

| Слово | Значение |
|-------|----------|
| `пер` | объявить изменяемую переменную |
| `знч` | объявить константу |
| `метод` | объявить метод (функцию/процедуру) |
| `возврат` | вернуть значение из метода |
| `если` / `тогда` | начало условия |
| `иначеесли` | другая ветка условия |
| `иначе` | ветка «во всех остальных случаях» |
| `для` / `пока` / `цикл` | циклы |
| `для каждого` / `из` | перебор коллекции |
| `и` / `или` / `не` | логические операции |
| `Истина` / `Ложь` | значения типа Булево |
