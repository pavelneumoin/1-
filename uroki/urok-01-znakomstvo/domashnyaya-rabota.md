## Часть Б. Основные задачи ⭐⭐

**Б1. Анкета.** Выведи 4 строки: имя, город, хобби, любимый предмет.

**Б2. Меню кафе.** Выведи список из 4 блюд с ценами, например:
```
Пицца — 350
Сок — 90
Мороженое — 60
Чай — 50
```

**Б3. Квадрат.** Нарисуй из символа `#` квадрат 4 × 4:
```
####
####
####
####
```

**Б4. Стрелка.** Нарисуй из символов стрелку вправо:
```
   *
   **
*****
   **
   *
```

**Б5. Найди и исправь 3 ошибки:**
```
метод Скрипт
    Консоль.Записать(Привет)
    Консоль.Записать("Пока")
```

## Часть В. Со звёздочкой ⭐⭐⭐

**В1. Лесенка вниз.** Сделай «лесенку» из звёздочек в 5 ступенек
(1, 2, 3, 4, 5 звёзд в строке).

**В2. Первая буква имени.** Нарисуй из символов большую первую букву
своего имени, высотой примерно 5 строк. Например, буква `Т`:
```
*****
  *
  *
  *
  *
```

**В3. Свой рисунок.** Придумай рисунок из символов (флаг, ёлка, робот) —
минимум 6 строк.
