<!-- kicker: Урок 1 -->

# Привет, <span class="accent">мир!</span>

## Твоя первая программа на 1С:Элемент

Сегодня ты заставишь компьютер сделать то, что скажешь. Серьёзно.

---

<!-- kicker: Зачем это -->

# Кто на самом деле тут главный?

Игры, чат, любимое приложение, кассы в магазине, банк — **всем этим
управляют программы**. А программы пишут люди.

Сегодня ты переходишь на сторону тех, кто **командует** компьютером,
а не просто нажимает кнопки.

---

<!-- kicker: Идея -->

# Что такое программа

**Программа** — это список команд. Компьютер выполняет их строго
**сверху вниз**, одну за другой, как рецепт.

<div class="callout fun"><span class="lead">Факт</span>
Компьютер супербыстрый, но буквальный: делает ровно то, что написано.
Забыл сказать «посоли» — суп будет без соли.</div>

---

<!-- kicker: Среда -->

# Где мы будем колдовать

Пишем код в облачной среде **1С:Предприятие.Элемент Скрипт** — прямо
в браузере.

- ничего не нужно устанавливать;
- открыл, вошёл — и можно писать;
- нажал «Запустить» — и код ожил.

---

<!-- kicker: Первая команда -->

# Скажи компьютеру «Привет»

Чтобы программа что-то показала на экране, есть команда:

```eos
Консоль.Записать("Привет, мир!")
```

- `Консоль` — это экран для текста;
- `Записать(...)` — команда «покажи вот это»;
- в кавычках `" "` — текст, который увидим.

---

<!-- kicker: Точка старта -->

# С чего начинается программа

Команды живут не сами по себе, а внутри **метода `Скрипт`** — это
точка входа, отсюда всё стартует:

```eos
метод Скрипт()
    Консоль.Записать("Привет, мир!")
;
```

И запомни золотое правило: **каждый такой блок закрывается `;`**.

---

<!-- kicker: Разбор -->

# Разбираем по косточкам

```eos
метод Скрипт()            // тут начинается программа
    Консоль.Записать("Привет, мир!")   // команда (с отступом!)
;                         // блок закончился
```

Отступ (несколько пробелов) показывает: команда **внутри** метода.
Среда сама подсказывает отступы — не воюй с ними, дружи.

---

<!-- kicker: Запуск -->

# Три секунды до магии

1. Набрал код.
2. Нажал «Запустить».
3. Внизу, в консоли, появилось:

```out
Привет, мир!
```

★ Поздравляю — это уже **настоящая программа**. Ты только что
запрограммировал компьютер.

<!-- kicker: Много строк -->

# Программа-болтушка

Команд может быть сколько угодно — они выполнятся одна за другой:

```eos
метод Скрипт()
    Консоль.Записать("Меня зовут Бит")
    Консоль.Записать("Я люблю код")
    Консоль.Записать("И пиццу")
;
```

```out
Меня зовут Бит
Я люблю код
И пиццу
```

---

<!-- kicker: Лайфхак -->

# Заметки для себя — комментарии

Комментарий — это текст для человека. Компьютер его **не выполняет**.

```eos
метод Скрипт()
    // это комментарий, программа его не видит
    Консоль.Записать("А это — увидит и выполнит")
;
```

<div class="callout tip"><span class="lead">Совет</span>
Комментарии помогают не запутаться в своём же коде. Профи пишут их постоянно.</div>

---

<!-- kicker: Ловушки -->

# Ошибка — это не страшно

Красное сообщение — не приговор, а подсказка, что поправить. На первом
уроке чаще всего ловят на трёх вещах:

<div class="callout warn"><span class="lead">Внимание</span>
1. забыли кавычки <code>" "</code> вокруг текста;
2. забыли <code>;</code> в конце блока;
3. написали команду вне <code>метод Скрипт()</code>.</div>

Программисты исправляют ошибки каждый день — это часть игры.

<!-- class: content -->

# Слабо нарисовать ёлку?

Из обычных символов можно рисовать! Попробуй вывести вот это:

```out
  *
 ***
*****
```

<div class="callout"><span class="lead">Подсказка</span>
Каждая строчка рисунка — отдельная команда <code>Консоль.Записать</code>.
Следи за пробелами <em>внутри</em> кавычек.</div>

---

<!-- kicker: Итоги -->

# Что мы узнали

- программа — это команды, они идут **сверху вниз**;
- `Консоль.Записать("...")` выводит текст на экран;
- программа живёт внутри `метод Скрипт()`, блок закрывается `;`;
- `//` — комментарий для человека;
- ошибка — это подсказка, а не провал.

**Дальше:** рабочий лист — пишем свои первые программы.
