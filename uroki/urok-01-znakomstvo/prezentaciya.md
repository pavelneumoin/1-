# Урок 1. Знакомство

## Программирование на 1С:Элемент

Первая программа — «Привет, мир!»

---

# Что такое программа?

**Программа** — это список команд для компьютера.

Компьютер выполняет команды **сверху вниз**, одну за другой,
ровно так, как мы их написали.

Сегодня мы напишем свою первую программу и запустим её.

---

# Где мы будем писать код

Мы программируем в среде **1С:Предприятие.Элемент Скрипт**
прямо в браузере.

- ничего не нужно устанавливать;
- открыли сайт, вошли — и можно писать код;
- нажал «Запустить» — программа выполнилась.

---

# Главная команда: вывод текста

Чтобы программа что-то показала на экране, используем команду:

```
Консоль.Записать("Привет, мир!")
```

- `Консоль` — это «экран», куда выводится текст.
- `Записать(...)` — команда «напиши вот это».
- В кавычках `" "` — текст, который мы хотим показать.

---

# С чего начинается любая программа

Команды нельзя писать «просто так» — они должны быть внутри
**метода с именем `Скрипт`**. Это точка, с которой всё начинается:

```
метод Скрипт()
    Консоль.Записать("Привет, мир!")
;
```

Запомним правило: каждый такой блок **закрывается `;`** в конце.

---

# Разбираем по частям

```
метод Скрипт()              ← начало программы
    Консоль.Записать("...")  ← команда (с отступом!)
;                            ← конец блока
```

- `метод Скрипт()` — «вот тут начинается моя программа».
- Команды внутри пишем **с отступом** (несколько пробелов) —
  так видно, что они «внутри».
- `;` — «блок закончился».

---

# Запускаем!

1. Набрали код.
2. Нажали «Запустить».
3. Внизу, в консоли, появилось:

```
Привет, мир!
```

🎉 Это уже настоящая программа.

---

# Меняем текст

Текст в кавычках можно написать любой:

```
метод Скрипт()
    Консоль.Записать("Меня зовут Аня")
;
```

Результат:

```
Меня зовут Аня
```

---

# Несколько строк

Команд может быть много — они выполнятся по очереди:

```
метод Скрипт()
    Консоль.Записать("Строка один")
    Консоль.Записать("Строка два")
    Консоль.Записать("Строка три")
;
```

Вывод:

```
Строка один
Строка два
Строка три
```

---

# Комментарии

Комментарий — это заметка для человека. Компьютер её **не выполняет**.

```
метод Скрипт()
    // это комментарий, программа его не видит
    Консоль.Записать("А это выполнится")
;
```

Комментарии помогают не запутаться в своём же коде.

---

# Если появилась ошибка — это нормально

Красное сообщение — не страшно. Это подсказка, что поправить.

Частые причины на первом уроке:
- забыли кавычки `" "` вокруг текста;
- забыли `;` в конце;
- написали команду вне `метод Скрипт()`.

Программисты исправляют ошибки постоянно — это часть работы.

---

# Что мы узнали

- Программа — это команды, выполняются сверху вниз.
- `Консоль.Записать("...")` — выводит текст на экран.
- Любая программа живёт внутри `метод Скрипт()`, блок закрывается `;`.
- `//` — комментарий для человека.
