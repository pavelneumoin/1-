# Урок 1. Решения (для преподавателя)

Цель урока: ученик понимает, что программа — это команды, умеет вывести
текст через `Консоль.Записать` и запустить код в среде Элемент Скрипт.

---

## Задание 1 ⭐

```
метод Скрипт()
    Консоль.Записать("Привет, мир!")
;
```

В консоли: `Привет, мир!`

---

## Задание 2 ⭐

```
метод Скрипт()
    Консоль.Записать("Меня зовут Аня")
;
```

(имя — любое; главное, что текст в кавычках и команда внутри метода)

---

## Задание 3 ⭐⭐

```
метод Скрипт()
    Консоль.Записать("Я учусь программировать")
    Консоль.Записать("Язык — 1С:Элемент")
    Консоль.Записать("Это мой первый урок")
;
```

Проверяем, что команды идут по очереди и каждая в своих кавычках.

---

## Задание 4 ⭐⭐ — Найди ошибку

Исправленный вариант:

```
метод Скрипт()
    Консоль.Записать("Привет")
    Консоль.Записать("Пока")
;
```

Ошибки:
1. `Записать(Привет)` — текст без кавычек. Нужно `"Привет"`.
2. `Записать("Пока"` — не закрыта скобка `)`. Нужно `Записать("Пока")`.
3. (как следствие незакрытой скобки) блок оформлен неверно — после
   исправления скобки всё встаёт на места. Если ученик назвал «не хватает
   закрывающей скобки» — засчитываем.

> Подсказка ученику: читать ошибку среды и смотреть, на какую строку
> она указывает.

---

## Задание 5 ⭐⭐

```
метод Скрипт()
    // программа выводит моё имя
    Консоль.Записать("Меня зовут Аня")
;
```

Главное — комментарий начинается с `//` и среда не считает его командой.

---

## Задание 6 ⭐⭐⭐ — Ёлочка

```
метод Скрипт()
    Консоль.Записать("  *")
    Консоль.Записать(" ***")
    Консоль.Записать("*****")
;
```

Обратите внимание на пробелы **внутри кавычек** — именно они задают форму.
Частая ошибка: пробелы ставят вне кавычек, и рисунок «съезжает».

## Домашняя работа — ответы (лист `domashnyaya-rabota.md`)

**Блиц (в классе):** простые программы вывода; задание 6 — добавить `//`.

**Часть А.** А1–А4 — по одной строке `Консоль.Записать("...")`.
А5 — вывод `А` / `Б` / `В` тремя строками.

**Часть Б.**
- Б1 — 4 строки `Консоль.Записать`.
- Б2 — 4 строки «блюдо — цена» (всё в кавычках, как текст).
- Б3 (квадрат): 4 строки `"####"`.
- Б4 (стрелка):
```
метод Скрипт()
    Консоль.Записать("   *")
    Консоль.Записать("   **")
    Консоль.Записать("*****")
    Консоль.Записать("   **")
    Консоль.Записать("   *")
;
```
- Б5 — ошибки: нет `()` у `метод Скрипт`, `Привет` без кавычек,
  нет закрывающего `;`.

**Часть В.** В1 — лесенка из 5 строк. В2/В3 — любой осмысленный рисунок;
оцениваем аккуратность пробелов и то, что ученик довёл до запуска.

## На что обратить внимание

- Многие забывают `;` в конце блока — покажите сообщение об ошибке и
  свяжите его с правилом.
- Кто-то пишет команды вне `метод Скрипт()` — ничего не запускается.
- Похвалите за первый запуск: важно эмоционально закрепить успех.
