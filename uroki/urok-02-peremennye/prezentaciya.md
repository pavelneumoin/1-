# Урок 2. Переменные и типы данных

## Программирование на 1С:Элемент

Как программа запоминает данные

---

# Зачем нужны переменные

Программе часто нужно **что-то запомнить**: имя, счёт в игре, цену.

**Переменная** — это «коробочка с именем», в которой лежит значение.

- у коробочки есть **имя** (например, `Имя` или `Счёт`);
- внутри лежит **значение** (например, `"Аня"` или `0`);
- значение можно **достать** и **поменять**.

---

# Создаём переменную

Ключевое слово `пер` создаёт переменную:

```
пер Имя = "Аня"
пер Возраст = 12
```

Теперь имя `Имя` хранит текст `"Аня"`, а `Возраст` хранит число `12`.

---

# Используем переменную

Имя переменной можно подставлять в команды вместо значения:

```
метод Скрипт()
    пер Имя = "Аня"
    Консоль.Записать(Имя)
;
```

Вывод:

```
Аня
```

Заметь: `Имя` пишем **без кавычек** — мы хотим значение из коробочки,
а не слово «Имя».

---

# Значение можно менять

На то она и **пер**еменная:

```
метод Скрипт()
    пер Счёт = 0
    Консоль.Записать(Счёт)     // 0
    Счёт = 5
    Консоль.Записать(Счёт)     // 5
    Счёт = Счёт + 1
    Консоль.Записать(Счёт)     // 6
;
```

`Счёт = Счёт + 1` — «возьми старое значение, прибавь 1, положи обратно».

---

# Константа: `знч`

Иногда значение менять **нельзя** — это `знч` (значение-константа):

```
знч Пи = 3.14
знч НазваниеШколы = "Гимназия №1"
```

Если попробовать изменить `знч` — программа сообщит об ошибке.
Это защита от случайной порчи важных данных.

---

# Типы данных

У каждого значения есть **тип** — какого оно «сорта»:

| Тип | Что хранит | Примеры |
|-----|------------|---------|
| `Строка` | текст | `"Привет"`, `"42"` |
| `Число` | числа | `0`, `-7`, `3.14` |
| `Булево` | да / нет | `Истина`, `Ложь` |

---

# Тип можно указать явно

Тип пишется **через двоеточие** после имени:

```
пер Имя: Строка = "Аня"
пер Возраст: Число = 12
пер Любит1С: Булево = Истина
```

Это делает код понятнее и помогает среде ловить ошибки.

---

# Строка и Число — это разное!

```
пер А = "5"     // это ТЕКСТ из одного символа
пер Б = 5       // это ЧИСЛО пять
```

- `"5"` нельзя умножать — это просто текст.
- `5` можно складывать и умножать.

Частая путаница новичков. Кавычки решают всё.

---

# Имена переменных

Хорошее имя переменной **говорит, что внутри**:

✅ `Возраст`, `Счёт`, `ИмяИгрока`, `Цена`

❌ `а`, `ххх`, `данные1` — непонятно, что там лежит

Правило: код читают люди. Имя должно подсказывать смысл.

---

# Собираем вместе

```
метод Скрипт()
    знч Школа = "Гимназия №1"
    пер Имя = "Аня"
    пер Класс = 6

    Консоль.Записать(Имя)
    Консоль.Записать(Класс)
    Консоль.Записать(Школа)
;
```

---

# Что мы узнали

- Переменная (`пер`) — коробочка с именем, значение можно менять.
- Константа (`знч`) — значение менять нельзя.
- Типы: `Строка` (текст), `Число`, `Булево` (да/нет).
- Тип указывается через `:` — `пер x: Число = 5`.
- `"5"` (текст) и `5` (число) — разные вещи.
