# Коробки для <span class="accent">данных</span>

## Переменные и типы в 1С:Элемент

Научим программу запоминать — имя, счёт в игре, что угодно.

---

<!-- kicker: Зачем -->

# Программе нужна память

Игра помнит твои очки. Чат помнит твоё имя. Магазин помнит цену.

Чтобы что-то запомнить, в программе есть **переменные** — коробочки,
в которых лежат значения.

---

<!-- kicker: Идея -->

# Что такое переменная

Представь коробку с наклейкой:

- на наклейке — **имя** (`Имя`, `Счёт`);
- внутри — **значение** (`"Аня"`, `0`);
- значение можно достать и **поменять**.

<div class="callout fun"><span class="lead">Образ</span>
Переменная — это коробка с подписью. Подпись не меняется, а вот
содержимое — запросто.</div>

---

<!-- kicker: Создаём -->
<!-- class: content tight -->

# Заводим переменную

Ключевое слово `пер` создаёт переменную:

```eos
метод Скрипт()
    пер Имя = "Аня"
    пер Возраст = 12
    Консоль.Записать(Имя)
    Консоль.Записать(Возраст)
;
```

```out
Аня
12
```

Заметь: `Имя` пишем **без кавычек** — нам нужно значение из коробки.

---

<!-- kicker: Меняем -->

# Значение можно менять

На то она и **пер**еменная:

```eos
метод Скрипт()
    пер Счёт = 0
    Консоль.Записать(Счёт)     // 0
    Счёт = 5
    Консоль.Записать(Счёт)     // 5
    Счёт = Счёт + 1
    Консоль.Записать(Счёт)     // 6
;
```

`Счёт = Счёт + 1` читается так: «возьми старое, прибавь 1, положи обратно».

---

<!-- kicker: Угадай -->
<!-- class: content -->

# Что выведет программа?

```eos
метод Скрипт()
    пер X = 10
    X = X + 5
    X = X * 2
    Консоль.Записать(X)
;
```

<div class="callout quiz"><span class="lead">Не подглядывай</span>
Посчитай по шагам в голове: чему станет равен <code>X</code>?</div>

---

<!-- kicker: Константы -->

# Когда менять нельзя — `знч`

Иногда значение должно быть **неизменным**. Тогда вместо `пер` берём `знч`:

```eos
знч Пи = 3.14
знч НазваниеШколы = "Гимназия №1"
```

<div class="callout warn"><span class="lead">Защита</span>
Попробуешь изменить <code>знч</code> — среда выдаст ошибку. Это нарочно:
важные данные защищены от случайной порчи.</div>

---

<!-- kicker: Типы -->

# У каждого значения есть «сорт»

Тип — это какого сорта значение:

| Тип | Что хранит | Примеры |
|-----|------------|---------|
| `Строка` | текст | `"Привет"`, `"42"` |
| `Число` | числа | `0`, `-7`, `3.14` |
| `Булево` | да / нет | `Истина`, `Ложь` |

---

<!-- kicker: Явный тип -->

# Тип можно указать явно

Тип пишут **через двоеточие** после имени:

```eos
пер Имя: Строка = "Аня"
пер Возраст: Число = 12
пер ЛюбитКод: Булево = Истина
```

Так код понятнее, а среда лучше ловит ошибки за тебя.

---

<!-- kicker: Ловушка -->

# `"5"` и `5` — это РАЗНОЕ!

```eos
пер А = "5"     // это ТЕКСТ из одного символа
пер Б = 5       // это ЧИСЛО пять
```

<div class="callout warn"><span class="lead">Главная путаница новичков</span>
<code>"5"</code> нельзя умножать — это просто текст.
<code>5</code> можно складывать и умножать. Всё решают кавычки.</div>

---

<!-- kicker: Лайфхак -->

# Имя должно говорить, что внутри

<div class="callout tip"><span class="lead">Правило хорошего кода</span>
Код читают люди. Имя переменной должно подсказывать смысл.</div>

✓ `Возраст`, `Счёт`, `ИмяИгрока`, `Цена`

✗ `а`, `ххх`, `данные1` — поди догадайся, что там лежит

---

<!-- kicker: Челлендж -->
<!-- class: content -->

# Слабо поменять местами?

Есть две коробки:

```eos
пер А = "лево"
пер Б = "право"
```

Сделай так, чтобы `А` стало `"право"`, а `Б` — `"лево"`.

<div class="callout"><span class="lead">Подсказка</span>
Понадобится третья коробка-«помощник». Почему — поймёшь, когда
попробуешь сделать без неё.</div>

---

<!-- kicker: Итоги -->

# Что мы узнали

- `пер` — переменная, значение можно менять;
- `знч` — константа, менять нельзя;
- типы: `Строка` (текст), `Число`, `Булево` (да/нет);
- тип указывают через `:` — `пер x: Число = 5`;
- `"5"` (текст) и `5` (число) — разные вещи.
