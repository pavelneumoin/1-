## Задание 7 ⭐⭐⭐ — Обмен значений

Есть две переменные:

```
пер А = "лево"
пер Б = "право"
```

Сделай так, чтобы после твоего кода `А` хранила `"право"`, а `Б` — `"лево"`.

Подсказка: понадобится третья переменная-«помощник».

```
метод Скрипт()
    пер А = "лево"
    пер Б = "право"
    // твой код



    Консоль.Записать(А)   // должно быть: право
    Консоль.Записать(Б)   // должно быть: лево
;
```
