# Урок 2. Решения (для преподавателя)

Цель урока: ученик создаёт переменные (`пер`) и константы (`знч`),
различает типы `Строка` / `Число` / `Булево`, умеет менять значение.

```
метод Скрипт()

    Консоль.Записать(Город)
;
```

## Задание 4 ⭐⭐

```
пер А = 7        →  число
пер Б = "7"      →  текст (строка)
пер В = "семь"   →  текст (строка)
пер Г = 3.14     →  число
```

Ключевая идея: кавычки делают значение текстом, без кавычек число — это число.

## Задание 7 ⭐⭐⭐ — Обмен

```
метод Скрипт()
    пер А = "лево"
    пер Б = "право"

    пер Помощник = А    // запомнили "лево"
    А = Б               // А стало "право"
    Б = Помощник        // Б стало "лево"

    Консоль.Записать(А)   // право
    Консоль.Записать(Б)   // лево
;
```

Классическая задача на обмен через временную переменную. Если ученик
попробует без помощника (`А = Б; Б = А`) — оба станут `"право"`; это
отличный повод разобрать, почему так.

## Домашняя практика — ответы

**ДЗ-1 (карточка героя).**
```
метод Скрипт()
    пер Имя = "Рыцарь"
    пер Сила = 50
    пер Жив = Истина
    Консоль.Записать(Имя)
    Консоль.Записать(Сила)
    Консоль.Записать(Жив)
    Сила = Сила + 10
    Консоль.Записать(Сила)   // 60
;
```

**ДЗ-2.** 5 переменных с осмысленными именами и вывод. Оцениваем имена.

**ДЗ-3.** Например: `Очки = Очки + 40` → 40, `Очки = Очки * 2` → 80,
`Очки = Очки + 20` → 100. Вариантов много.

**ДЗ-4 (тройной обмен).** Через временную переменную, например:
```
пер t = А    // 1
А = В         // 3
В = Б         // 2
Б = t         // 1
```
Итог: `А=3, Б=1, В=2`.

## Типичные ошибки

- Выводят `"Имя"` в кавычках и удивляются, почему печатается слово, а не
  значение. Показать разницу `Записать(Имя)` и `Записать("Имя")`.
- Пробуют умножать `"5"` (строку). Связать с уроком про числа (урок 4).
- Путают `пер` и `знч` — напомнить: `знч` про «значение, которое не меняется».
