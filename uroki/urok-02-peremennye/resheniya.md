## Задание 7 ⭐⭐⭐ — Обмен

```
метод Скрипт()
    пер А = "лево"
    пер Б = "право"

    пер Помощник = А    // запомнили "лево"
    А = Б               // А стало "право"
    Б = Помощник        // Б стало "лево"

    Консоль.Записать(А)   // право
    Консоль.Записать(Б)   // лево
;
```

Классическая задача на обмен через временную переменную. Если ученик
попробует без помощника (`А = Б; Б = А`) — оба станут `"право"`; это
отличный повод разобрать, почему так.

## Домашняя работа — ответы (лист `domashnyaya-rabota.md`)

**Блиц:** 1) 3, затем 10; 4) `Х` → 11; 5) число, текст, булево, число, текст;
6) понятное имя, напр. `КличкаКота`.

**Часть А.** А3 — текст/число/булево/число/число/текст. А4 — `Х` = 10.

**Часть Б.**
- Б1 — три переменные и вывод.
- Б2 — после `+25` и `*2`: например 50 → 75 → 150.
- Б3 — счёт меняется тремя присваиваниями, вывод после каждого.
- Б4 — `А` = 99, `Б` = 10 (Б скопировала старое значение А — важный момент!).
- Б5 — напр. `Город`, `Температура`.

**Часть В.**
- В1 (обмен): через помощник — `t = А; А = Б; Б = t`.
- В2 (сдвиг): `t = А; А = В; В = Б; Б = t` → `А=3, Б=1, В=2`.
- В3 (кошелёк): `Деньги = Деньги - <сумма>` три раза, вывод остатка.

## Типичные ошибки

- Выводят `"Имя"` в кавычках и удивляются, почему печатается слово, а не
  значение. Показать разницу `Записать(Имя)` и `Записать("Имя")`.
- Пробуют умножать `"5"` (строку). Связать с уроком про числа (урок 4).
- Путают `пер` и `знч` — напомнить: `знч` про «значение, которое не меняется».
