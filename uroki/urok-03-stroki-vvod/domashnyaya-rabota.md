# Урок 3. Домашняя работа — Ввод и строки

**Имя:** _________________________  **Дата:** ____________

Памятка:
```
пер Имя = Консоль.СчитатьСтроку("Вопрос: ")   // текст
пер N   = Консоль.СчитатьЧисло("Вопрос: ")    // число
Консоль.Записать("Привет, " + Имя)            // склейка +
Консоль.Записать("Привет, $Имя")              // подстановка $
```

---

## Часть А. Разминка ⭐

**А1.** Спроси имя и поздоровайся: `Привет, <имя>!`

**А2.** Спроси город и выведи `Ты живёшь в городе <город>`.

**А3.** Спроси любимое число и выведи `Твоё число — <число>`.

**А4. Склей две строки.** Дано `пер Имя = "Кот"`, `пер Кличка = "Барсик"`.
Выведи `Кот по кличке Барсик` через `+`.

**А5.** То же, что А4, но через подстановку `$`.

---

## Часть Б. Основные задачи ⭐⭐

**Б1. Анкета.** Спроси имя, возраст (числом) и любимый предмет. Выведи
одной строкой: `<Имя>, <возраст> лет, любит <предмет>`.

**Б2. Безумная история (Mad Libs).** Спроси существительное, глагол и
животное. Вставь их в смешную фразу:
`Однажды $Существительное решило $Глагол вместе с $Животное`.

**Б3. Знакомство роботов.** Спроси два имени и выведи:
`$Имя1 и $Имя2 теперь друзья!`

**Б4. Найди ошибку.** Почему выводится слово «Имя», а не введённое имя?
```
пер Имя = Консоль.СчитатьСтроку("Имя: ")
Консоль.Записать("Привет, Имя")
```
Исправь.

**Б5. Эхо.** Спроси любое слово и выведи его три раза в трёх строках.

## Часть В. Со звёздочкой ⭐⭐⭐

**В1. Визитка.** Спроси имя, профессию, город. Выведи аккуратную визитку
в рамке из символов, используя `$`.

**В2. Полное имя.** Спроси отдельно имя и фамилию. Выведи:
`Здравствуйте, <Имя> <Фамилия>!` — двумя способами (через `+` и через `$`).

**В3. Приглашение.** Спроси имя друга, дату и место. Составь текст
приглашения на день рождения из 3–4 строк с подстановками.
