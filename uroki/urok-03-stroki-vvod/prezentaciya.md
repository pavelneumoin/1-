# Урок 3. Ввод и работа со строками

## Программирование на 1С:Элемент

Программа, которая «разговаривает» с человеком

---

# Программа может спрашивать

До сих пор программа только говорила. Теперь научим её **слушать** —
спрашивать что-то у человека и запоминать ответ.

Для этого есть команда **`Консоль.СчитатьСтроку`**.

---

# Считываем строку

```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Как тебя зовут? ")
    Консоль.Записать(Имя)
;
```

Что происходит:
1. На экране появляется вопрос `Как тебя зовут?`.
2. Человек печатает ответ, например `Аня`.
3. Ответ попадает в переменную `Имя`.

---

# Склеиваем строки: `+`

Две строки можно соединить знаком `+`:

```
пер Имя = "Аня"
Консоль.Записать("Привет, " + Имя + "!")
```

Вывод:

```
Привет, Аня!
```

Обрати внимание на пробел внутри `"Привет, "` — без него слиплось бы.

---

# Подстановка через `$` (интерполяция)

Есть способ короче — подставить переменную **прямо в текст** через `$`:

```
пер Имя = "Аня"
Консоль.Записать("Привет, $Имя!")
```

Вывод:

```
Привет, Аня!
```

`$Имя` внутри кавычек заменяется на значение переменной.

---

# Два способа — один результат

```
// способ 1: склейка
Консоль.Записать("Тебе " + Возраст + " лет")

// способ 2: подстановка
Консоль.Записать("Тебе $Возраст лет")
```

Оба выведут одно и то же. Второй — короче и читается легче.

---

# Диалог с человеком

```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Имя: ")
    пер Город = Консоль.СчитатьСтроку("Город: ")
    Консоль.Записать("$Имя из города $Город — привет!")
;
```

Пример работы:

```
Имя: Аня
Город: Казань
Аня из города Казань — привет!
```

---

# Считать число

Если нужен именно **ответ-число**, используем `СчитатьЧисло`:

```
пер Возраст = Консоль.СчитатьЧисло("Сколько тебе лет? ")
пер ЧерезГод = Возраст + 1
Консоль.Записать("Через год будет $ЧерезГод")
```

`СчитатьЧисло` сразу даёт число, с которым можно считать.

---

# Строка vs число при вводе

| Команда | Что вернёт | Когда использовать |
|---------|------------|--------------------|
| `СчитатьСтроку` | текст (`Строка`) | имя, город, слово |
| `СчитатьЧисло` | число (`Число`) | возраст, количество, цена |

Если число прочитать как строку — с ним нельзя будет считать!

---

# Собираем мини-диалог

```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Твоё имя: ")
    пер Лет = Консоль.СчитатьЧисло("Сколько тебе лет: ")
    знч ЧерезДесять = Лет + 10
    Консоль.Записать("$Имя, через 10 лет тебе будет $ЧерезДесять!")
;
```

---

# Что мы узнали

- `Консоль.СчитатьСтроку("вопрос")` — спросить и получить текст.
- `Консоль.СчитатьЧисло("вопрос")` — спросить и получить число.
- Склейка строк через `+`.
- Подстановка переменной в текст через `$Имя`.
