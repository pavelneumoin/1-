# Программа, которая <span class="accent">говорит</span>

## Ввод и работа со строками

Сделаем программу, которая спрашивает и отвечает — как живая.

---

<!-- kicker: Идея -->

# Пусть программа слушает

Раньше программа только говорила. Теперь научим её **слушать** —
спрашивать и запоминать ответ.

Для этого есть команда **`Консоль.СчитатьСтроку`**.

---

<!-- kicker: Ввод -->

# Спрашиваем имя

```eos
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Как тебя зовут? ")
    Консоль.Записать(Имя)
;
```

Что происходит по шагам:

1. на экране появляется вопрос;
2. человек печатает ответ, например `Аня`;
3. ответ попадает в переменную `Имя`.

---

<!-- kicker: Склейка -->

# Соединяем строки через `+`

Две строки можно склеить знаком `+`:

```eos
пер Имя = "Аня"
Консоль.Записать("Привет, " + Имя + "!")
```

```out
Привет, Аня!
```

<div class="callout warn"><span class="lead">Не забудь пробел</span>
В <code>"Привет, "</code> пробел внутри кавычек не случаен — без него
слова слипнутся: <code>Привет,Аня</code>.</div>

---

<!-- kicker: Лайфхак -->

# Способ короче — подстановка `$`

Можно вставить переменную **прямо в текст** через `$`:

```eos
пер Имя = "Аня"
Консоль.Записать("Привет, $Имя!")
```

```out
Привет, Аня!
```

<div class="callout tip"><span class="lead">Совет</span>
<code>$Имя</code> внутри кавычек заменяется на значение. Это короче склейки
и читается легче — пользуйся им.</div>

---

<!-- kicker: Диалог -->

# Программа ведёт беседу

```eos
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Имя: ")
    пер Город = Консоль.СчитатьСтроку("Город: ")
    Консоль.Записать("$Имя из города $Город — привет!")
;
```

```out
Имя: Аня
Город: Казань
Аня из города Казань — привет!
```

---

<!-- kicker: Числа -->

# Если нужен ответ-число

Для чисел берём `СчитатьЧисло` — тогда с ответом можно считать:

```eos
пер Возраст = Консоль.СчитатьЧисло("Сколько тебе лет? ")
пер ЧерезГод = Возраст + 1
Консоль.Записать("Через год будет $ЧерезГод")
;
```

---

<!-- kicker: Важно -->

# Строка или число при вводе?

| Команда | Что вернёт | Когда брать |
|---------|------------|-------------|
| `СчитатьСтроку` | текст (`Строка`) | имя, город, слово |
| `СчитатьЧисло` | число (`Число`) | возраст, количество, цена |

<div class="callout warn"><span class="lead">Ловушка</span>
Прочитаешь число как строку — и с ним нельзя будет считать.</div>

# Что выведет программа?

Пользователь ввёл имя `Бит`:

```eos
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Имя: ")
    Консоль.Записать("Привет, Имя")
;
```

<div class="callout quiz"><span class="lead">Внимание на кавычки</span>
Выведется имя <code>Бит</code> — или что-то другое? Почему?</div>

# Собери мини-диалог

Спроси имя и возраст (числом) и выведи дружелюбную фразу:

```out
Твоё имя: Аня
Сколько тебе лет: 12
Аня, через 10 лет тебе будет 22!
```

<div class="callout"><span class="lead">Подсказка</span>
Возраст читай через <code>СчитатьЧисло</code>, чтобы прибавить 10.
В выводе используй подстановку <code>$</code>.</div>

# Что мы узнали

- `СчитатьСтроку("вопрос")` — спросить и получить текст;
- `СчитатьЧисло("вопрос")` — спросить и получить число;
- склейка строк через `+` (не забудь пробелы);
- подстановка переменной через `$Имя` — коротко и удобно.
