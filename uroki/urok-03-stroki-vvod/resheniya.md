# Урок 3. Решения (для преподавателя)

Цель урока: ученик умеет считывать ввод (`СчитатьСтроку` / `СчитатьЧисло`),
склеивать строки через `+` и подставлять переменные через `$`.

---

## Задание 1 ⭐

```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Как тебя зовут? ")
    Консоль.Записать("Привет, $Имя!")
;
```

---

## Задание 2 ⭐

```
метод Скрипт()
    пер Цвет = Консоль.СчитатьСтроку("Любимый цвет: ")
    пер Животное = Консоль.СчитатьСтроку("Любимое животное: ")
    Консоль.Записать("Тебе нравится $Цвет цвет и $Животное")
;
```

---

## Задание 3 ⭐⭐

```
метод Скрипт()
    пер Возраст = Консоль.СчитатьЧисло("Сколько тебе лет? ")
    пер ЧерезГод = Возраст + 1
    Консоль.Записать("Через год тебе будет $ЧерезГод")
;
```

Важно: именно `СчитатьЧисло`, иначе `Возраст + 1` сработает не как сложение.

## Задание 4 ⭐⭐

```
метод Скрипт()
    пер Имя = "Аня"
    Консоль.Записать("Меня зовут " + Имя)   // способ 1
    Консоль.Записать("Меня зовут $Имя")     // способ 2
;
```

---

## Задание 5 ⭐⭐

```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Имя: ")
    пер Город = Консоль.СчитатьСтроку("Город: ")
    пер Возраст = Консоль.СчитатьЧисло("Возраст: ")
    Консоль.Записать("$Имя, $Возраст лет, город $Город")
;
```

---

## Задание 6 ⭐⭐ — Найди ошибку

Причина: `"Привет, Имя"` — слово `Имя` написано как обычный текст внутри
кавычек, без `$`. Поэтому выводится буквально «Имя».

Исправление:

```
Консоль.Записать("Привет, $Имя")
```

(или через склейку: `"Привет, " + Имя`)

## Задание 7 ⭐⭐⭐

```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Имя: ")
    пер N = Консоль.СчитатьЧисло("Введите число: ")
    пер Удвоенное = N + N
    Консоль.Записать("Привет, $Имя!")
    Консоль.Записать("Удвоенное число: $Удвоенное")
;
```

## Домашняя практика — ответы

**ДЗ-1 (визитка).**
```
метод Скрипт()
    пер Имя = Консоль.СчитатьСтроку("Имя: ")
    пер Профессия = Консоль.СчитатьСтроку("Профессия: ")
    пер Город = Консоль.СчитатьСтроку("Город: ")
    Консоль.Записать("=== Визитка ===")
    Консоль.Записать("Имя: $Имя")
    Консоль.Записать("Профессия: $Профессия")
    Консоль.Записать("Город: $Город")
;
```

**ДЗ-2 (Mad Libs).** Три `СчитатьСтроку` + одна строка с подстановками
`$Существительное`, `$Глагол`, `$Животное`. Смех в классе гарантирован —
это и есть цель: ученик видит силу интерполяции.

**ДЗ-3 (анкета).** Имя и игра — `СчитатьСтроку`, возраст — `СчитатьЧисло`,
вывод одной строкой через `$`.

**ДЗ-4.** Два имени, фраза двумя способами:
`"Привет, " + А + " и " + Б` и `"Привет, $А и $Б"`.

---

## Типичные ошибки

- Забывают `$` и выводят имя переменной как текст (см. задание 6).
- Используют `СчитатьСтроку` там, где нужно число, и потом не могут
  выполнить арифметику. Связать с уроком 4.
- Забывают пробелы внутри кавычек при склейке: `"Привет,"+Имя` → слипается.
