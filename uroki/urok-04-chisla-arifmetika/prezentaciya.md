# Компьютер <span class="accent">считает</span>

## Числа и арифметика в 1С:Элемент

Превратим программу в калькулятор, который сильнее тебя в счёте.

---

<!-- kicker: Операции -->

# Четыре главных действия

С числами (`Число`) можно делать арифметику:

| Действие | Знак | Пример | Результат |
|----------|------|--------|-----------|
| сложение | `+` | `5 + 3` | `8` |
| вычитание | `-` | `5 - 3` | `2` |
| умножение | `*` | `5 * 3` | `15` |
| деление | `/` | `8 / 2` | `4` |

---

<!-- kicker: Считаем -->

# Посчитал — вывел

```eos
метод Скрипт()
    пер А = 8
    пер Б = 3
    Консоль.Записать(А + Б)    // 11
    Консоль.Записать(А * Б)    // 24
;
```

Результат можно сразу вывести, а можно сохранить в переменную и
использовать дальше.

<!-- kicker: Жизнь -->

# Считаем стоимость покупки

```eos
метод Скрипт()
    пер Цена = 100
    пер Количество = 3
    пер Итог = Цена * Количество
    Консоль.Записать("Итого: $Итог рублей")
;
```

```out
Итого: 300 рублей
```

Это уже похоже на настоящую программу из магазина.

<!-- kicker: Порядок -->

# Сначала умножение, потом сложение

Как в математике: сначала `*` и `/`, потом `+` и `-`.

```eos
2 + 3 * 4      // = 14  (сначала 3*4, потом +2)
(2 + 3) * 4    // = 20  (скобки меняют порядок)
```

<div class="callout tip"><span class="lead">Лайфхак</span>
Не уверен в порядке — ставь скобки <code>( )</code>. Они никогда не лишние
и делают формулу понятной.</div>

# Чему равно?

```eos
метод Скрипт()
    пер Очки = 0
    Очки = Очки + 5
    Очки = Очки + 3
    Очки = Очки * 2
    Консоль.Записать(Очки)
;
```

<div class="callout quiz"><span class="lead">Посчитай по шагам</span>
Иди сверху вниз и держи в голове текущее значение <code>Очки</code>.</div>

<!-- kicker: Дроби -->

# Деление бывает с дробью

```eos
Консоль.Записать(7 / 2)    // 3.5
```

Число с точкой — это тоже `Число`:

```eos
знч Пи = 3.14
пер Радиус = 5
Консоль.Записать(Пи * Радиус * Радиус)   // 78.5
```

---

<!-- kicker: Ловушка -->

# Складываешь текст с числом? Скобки!

```eos
Консоль.Записать("Сумма: " + А + Б)     // склеит как текст!
Консоль.Записать("Сумма: " + (А + Б))   // правильно: сначала посчитать
```

<div class="callout warn"><span class="lead">Почему так</span>
Без скобок <code>+</code> может склеить числа как строки. Скобки говорят:
«сначала посчитай, потом приклеивай». Ещё надёжнее — подстановка
<code>$</code>.</div>

<!-- kicker: Применяем -->

# Средний балл за три оценки

```eos
метод Скрипт()
    пер О1 = Консоль.СчитатьЧисло("Оценка 1: ")
    пер О2 = Консоль.СчитатьЧисло("Оценка 2: ")
    пер О3 = Консоль.СчитатьЧисло("Оценка 3: ")
    пер Средний = (О1 + О2 + О3) / 3
    Консоль.Записать("Средний балл: $Средний")
;
```

Скобки вокруг суммы — обязательны, иначе посчитает неверно.

# Слабо посчитать сдачу?

Спроси стоимость покупки и сумму, которую дал покупатель. Выведи сдачу.

```out
Стоимость покупки: 270
Сколько дал покупатель: 500
Сдача: 230 рублей
```

# Что мы узнали

- операции `+`, `-`, `*`, `/` и порядок действий;
- скобки `( )` меняют приоритет;
- дробные числа (`3.5`, `3.14`);
- накопление через `Счёт = Счёт + ...`;
- склейка строки с числом — в скобки или через `$`.
