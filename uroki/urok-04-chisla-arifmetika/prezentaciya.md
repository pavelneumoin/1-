# Урок 4. Числа и арифметика

## Программирование на 1С:Элемент

Учим программу считать

---

# Компьютер — отличный калькулятор

С числами (`Число`) можно выполнять арифметику:

| Действие | Знак | Пример | Результат |
|----------|------|--------|-----------|
| сложение | `+` | `5 + 3` | `8` |
| вычитание | `-` | `5 - 3` | `2` |
| умножение | `*` | `5 * 3` | `15` |
| деление | `/` | `8 / 2` | `4` |

---

# Считаем и выводим

```
метод Скрипт()
    пер А = 8
    пер Б = 3
    Консоль.Записать(А + Б)    // 11
    Консоль.Записать(А - Б)    // 5
    Консоль.Записать(А * Б)    // 24
;
```

Результат вычисления можно сразу вывести или сохранить в переменную.

---

# Результат в переменную

```
метод Скрипт()
    пер Цена = 100
    пер Количество = 3
    пер Итог = Цена * Количество
    Консоль.Записать("Итого: $Итог рублей")   // Итого: 300 рублей
;
```

Это уже похоже на настоящую программу — расчёт стоимости покупки.

---

# Порядок действий

Как в математике: сначала `*` и `/`, потом `+` и `-`.

```
2 + 3 * 4      // = 14  (сначала 3*4=12, потом +2)
```

Скобки `( )` меняют порядок:

```
(2 + 3) * 4    // = 20  (сначала 2+3=5, потом *4)
```

---

# Деление бывает с дробью

```
Консоль.Записать(7 / 2)    // 3.5
```

Число с точкой — это тоже `Число` (дробное).

```
знч Пи = 3.14
пер Радиус = 5
Консоль.Записать(Пи * Радиус * Радиус)   // 78.5
```

---

# Накопление: счётчик

Очень частый приём — постепенно увеличивать переменную:

```
пер Счёт = 0
Счёт = Счёт + 1     // стало 1
Счёт = Счёт + 1     // стало 2
Счёт = Счёт + 10    // стало 12
```

Так в играх считают очки, а в магазинах — сумму в корзине.

---

# Считаем с тем, что ввёл человек

```
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Первое число: ")
    пер Б = Консоль.СчитатьЧисло("Второе число: ")
    Консоль.Записать("Сумма: " + (А + Б))
    Консоль.Записать("Произведение: " + (А * Б))
;
```

Программа считает то, что не знала заранее.

---

# Внимание: скобки при склейке

Когда складываешь строку и число, ставь арифметику в скобки:

```
Консоль.Записать("Сумма: " + А + Б)     // может склеить как текст!
Консоль.Записать("Сумма: " + (А + Б))   // правильно: сначала посчитать
```

Или используй подстановку — она надёжнее:

```
пер С = А + Б
Консоль.Записать("Сумма: $С")
```

---

# Практический пример: средний балл

```
метод Скрипт()
    пер О1 = Консоль.СчитатьЧисло("Оценка 1: ")
    пер О2 = Консоль.СчитатьЧисло("Оценка 2: ")
    пер О3 = Консоль.СчитатьЧисло("Оценка 3: ")
    пер Средний = (О1 + О2 + О3) / 3
    Консоль.Записать("Средний балл: $Средний")
;
```

# Что мы узнали

- Операции: `+`, `-`, `*`, `/`.
- Порядок действий и скобки `( )`.
- Дробные числа (`3.5`, `3.14`).
- Накопление через `Счёт = Счёт + ...`.
- При склейке строки и числа — арифметику в скобки или через `$`.
