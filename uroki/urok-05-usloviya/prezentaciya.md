# Урок 5. Условия: если / иначе

## Программирование на 1С:Элемент

Программа, которая принимает решения

---

# Программа может выбирать

До сих пор программа делала всё подряд. Теперь научим её **выбирать**:
делать одно, **если** что-то верно, и другое — в остальных случаях.

Пример из жизни: *если* на улице дождь — берём зонт, *иначе* — нет.

---

# Тип Булево: Истина или Ложь

Решение строится на ответе «да/нет». В программе это тип **`Булево`**:

```
пер Дождь: Булево = Истина
пер Каникулы: Булево = Ложь
```

Только два значения: `Истина` и `Ложь`.

---

# Сравнения дают Булево

Когда мы что-то сравниваем — получается `Истина` или `Ложь`:

| Запись | Смысл | Пример | Результат |
|--------|-------|--------|-----------|
| `=`  | равно | `5 = 5` | Истина |
| `<>` | не равно | `5 <> 3` | Истина |
| `>`  | больше | `5 > 3` | Истина |
| `<`  | меньше | `5 < 3` | Ложь |
| `>=` | больше или равно | `5 >= 5` | Истина |
| `<=` | меньше или равно | `3 <= 5` | Истина |

---

# Конструкция «если»

```
если Условие тогда
    // что делать, если условие Истина
;
```

Пример:

```
пер Возраст = 10
если Возраст >= 7 тогда
    Консоль.Записать("Можно идти в школу")
;
```

---

# «если ... иначе»

```
метод Скрипт()
    пер Оценка = Консоль.СчитатьЧисло("Оценка: ")
    если Оценка >= 3 тогда
        Консоль.Записать("Сдано!")
    иначе
        Консоль.Записать("Пересдача")
    ;
;
```

`иначе` — это «во всех остальных случаях».

---

# Несколько веток: «иначеесли»

```
если Оценка = 5 тогда
    Консоль.Записать("Отлично")
иначеесли Оценка = 4 тогда
    Консоль.Записать("Хорошо")
иначеесли Оценка = 3 тогда
    Консоль.Записать("Удовлетворительно")
иначе
    Консоль.Записать("Двойка")
;
```

Программа проверяет условия сверху вниз и выполняет **первое подходящее**.

---

# Логика: и / или / не

Условия можно объединять:

```
// оба должны быть истиной
если Возраст >= 7 и Возраст <= 17 тогда ...

// хотя бы одно
если День = "суббота" или День = "воскресенье" тогда ...

// отрицание
если не Дождь тогда ...
```

---

# Пример: проверка пароля

```
метод Скрипт()
    пер Пароль = Консоль.СчитатьСтроку("Введите пароль: ")
    если Пароль = "1234" тогда
        Консоль.Записать("Добро пожаловать!")
    иначе
        Консоль.Записать("Неверный пароль")
    ;
;
```

---

# Пример: чётное или нечётное

Остаток от деления на 2 проверяем оператором `%` (если доступен) или
сравнением. Идея: чётное число делится на 2 без остатка.

```
метод Скрипт()
    пер N = Консоль.СчитатьЧисло("Число: ")
    если N % 2 = 0 тогда
        Консоль.Записать("Чётное")
    иначе
        Консоль.Записать("Нечётное")
    ;
;
```

---

# Вложенные условия

Внутри одной ветки может быть другое условие:

```
если Возраст >= 7 тогда
    если Возраст <= 17 тогда
        Консоль.Записать("Школьный возраст")
    ;
;
```

Часто то же самое короче записать через `и`:
`если Возраст >= 7 и Возраст <= 17 тогда`

---

# Что мы узнали

- Тип `Булево`: `Истина` / `Ложь`.
- Сравнения: `=`, `<>`, `>`, `<`, `>=`, `<=`.
- `если ... тогда ... иначе ...` — ветвление.
- `иначеесли` — несколько вариантов.
- Логика: `и`, `или`, `не`.

**Дальше:** рабочий лист — учим программу принимать решения.
