# Программа <span class="accent">принимает решения</span>

## Условия: если / иначе

Научим программу выбирать — как ты выбираешь, брать ли зонт.

---

<!-- kicker: Идея -->

# Если… иначе…

До сих пор программа делала всё подряд. Теперь она будет **выбирать**:
одно — *если* что-то верно, другое — в остальных случаях.

Из жизни: *если* на улице дождь — берём зонт, *иначе* — нет.

---

<!-- kicker: Булево -->

# Истина или Ложь

Решение строится на ответе «да/нет». В программе это тип **`Булево`**:

```eos
пер Дождь: Булево = Истина
пер Каникулы: Булево = Ложь
```

Всего два значения: `Истина` и `Ложь`. Третьего не дано.

---

<!-- kicker: Сравнения -->

# Сравнили — получили да/нет

| Запись | Смысл | Пример | Ответ |
|--------|-------|--------|-------|
| `=`  | равно | `5 = 5` | Истина |
| `<>` | не равно | `5 <> 3` | Истина |
| `>` `<` | больше / меньше | `5 > 3` | Истина |
| `>=` `<=` | не меньше / не больше | `5 >= 5` | Истина |

---

<!-- kicker: Конструкция -->

# Пишем «если … иначе»

```eos
метод Скрипт()
    пер Оценка = Консоль.СчитатьЧисло("Оценка: ")
    если Оценка >= 3 тогда
        Консоль.Записать("Сдано!")
    иначе
        Консоль.Записать("Пересдача")
    ;
;
```

`иначе` — это «во всех остальных случаях». Блок закрываем `;`.

---

<!-- kicker: Много веток -->

# Несколько вариантов: «иначеесли»

```eos
если Оценка = 5 тогда
    Консоль.Записать("Отлично")
иначеесли Оценка = 4 тогда
    Консоль.Записать("Хорошо")
иначе
    Консоль.Записать("Бывает")
;
```

<div class="callout tip"><span class="lead">Как это работает</span>
Программа проверяет условия сверху вниз и выполняет
<strong>первое подходящее</strong>. Остальные пропускает.</div>

---

<!-- kicker: Логика -->

# Объединяем условия: и / или / не

```eos
// оба условия истинны
если Возраст >= 7 и Возраст <= 17 тогда ...

// хотя бы одно
если День = "суббота" или День = "воскресенье" тогда ...

// наоборот
если не Дождь тогда ...
```

---

<!-- kicker: Пример -->

# Проверка пароля

```eos
метод Скрипт()
    пер Пароль = Консоль.СчитатьСтроку("Введите пароль: ")
    если Пароль = "1234" тогда
        Консоль.Записать("Добро пожаловать!")
    иначе
        Консоль.Записать("Неверный пароль")
    ;
;
```

# Что выведет программа?

Пользователь ввёл `17`:

```eos
метод Скрипт()
    пер В = Консоль.СчитатьЧисло("Возраст: ")
    если В >= 18 тогда
        Консоль.Записать("Взрослый")
    иначеесли В >= 7 тогда
        Консоль.Записать("Школьник")
    иначе
        Консоль.Записать("Малыш")
    ;
;
```

<!-- kicker: Ловушка -->

# Диапазон пишем через «и»

<div class="callout warn"><span class="lead">Так нельзя</span>
<code>7 &lt;= Возраст &lt;= 17</code> — одной строкой не сработает.</div>

```eos
// правильно — через И:
если Возраст >= 7 и Возраст <= 17 тогда ...
```

<!-- kicker: Челлендж -->
<!-- class: content -->

# Слабо сделать билет в кино?

Цена билета зависит от возраста:

- до 7 лет — бесплатно (`0`);
- от 7 до 17 — `200`;
- иначе — `350`.

<div class="callout"><span class="lead">Подсказка</span>
Три ветки: <code>если</code> / <code>иначеесли</code> / <code>иначе</code>.
Для диапазона 7–17 используй <code>и</code>.</div>

# Что мы узнали

- тип `Булево`: `Истина` / `Ложь`;
- сравнения `=`, `<>`, `>`, `<`, `>=`, `<=`;
- `если … тогда … иначе …` — ветвление;
- `иначеесли` — несколько вариантов;
- логика `и`, `или`, `не`.
