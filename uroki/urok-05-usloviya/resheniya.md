# Урок 5. Решения (для преподавателя)

Цель урока: ученик использует `если/иначе/иначеесли`, сравнения и
логические операции `и`/`или`/`не` для ветвления программы.

> Про `%` (остаток от деления): если в среде оператор называется иначе
> или недоступен — найдите аналог в справочнике/автодополнении. Идея
> чётности важнее конкретного синтаксиса; см. задание 6.

## Домашняя работа — ответы (лист `domashnyaya-rabota.md`)

**Блиц:** 1) Истина, Истина, Ложь, Ложь; 6) при вводе `0` → `ноль или минус`.

**Часть А.** А1: Истина, Ложь, Ложь, Истина, Ложь, Истина. А4: при `5` → `плюс`.

**Часть Б.**
- Б1: `если Оценка >= 3 ... иначе ...`.
- Б2 (знак): `если N > 0 ... иначеесли N < 0 ... иначе Ноль`.
- Б3 (светофор): цепочка по строкам + финальное `иначе`.
- Б4 (оценка словами): `иначеесли` для 5/4/3, иначе `Плохо`.
- Б5: `если Дали >= Цена` → сдача, иначе `Не хватает`.
- Б6 (чёт/нечёт): `если N % 2 = 0`.

**Часть В.**
- В1 (кино): `< 7` бесплатно, `>= 7 и <= 17` → 200, иначе 350.
- В2 (макс из трёх): сравнить попарно через `если/иначеесли`.
- В3 (категория): `< 12` Ребёнок, `< 18` Подросток, иначе Взрослый.
- В4 (високосный, упрощённо): `если Год % 4 = 0`. Упомяните, что настоящее
  правило сложнее (исключения для веков).

> Про `%`: если оператора остатка нет под этим именем — найдите аналог в
> справочнике среды; важна идея, а не конкретный символ.

## Типичные ошибки

- Забывают `;`, закрывающий блок `если`.
- Пишут `Оценка = 5` и боятся, что это присваивание — пояснить, что в
  условии это сравнение.
- В диапазоне пишут `7 <= Возраст <= 17` одной строкой — нужно через `и`:
  `Возраст >= 7 и Возраст <= 17`.
- В цепочке `иначеесли` дублируют проверки — напомнить, что выполняется
  только первая подходящая ветка.
