# Урок 5. Решения (для преподавателя)

Цель урока: ученик использует `если/иначе/иначеесли`, сравнения и
логические операции `и`/`или`/`не` для ветвления программы.

> Про `%` (остаток от деления): если в среде оператор называется иначе
> или недоступен — найдите аналог в справочнике/автодополнении. Идея
> чётности важнее конкретного синтаксиса; см. задание 6.

---

## Задание 1 ⭐

```
5 > 2        → Истина
3 = 4        → Ложь
7 <> 7       → Ложь
10 >= 10     → Истина
2 < 1        → Ложь
```

## Домашняя практика — ответы

**ДЗ-1 (контроль входа).**
```
метод Скрипт()
    пер Слово = Консоль.СчитатьСтроку("Кодовое слово: ")
    если Слово = "сезам" тогда
        Консоль.Записать("Доступ разрешён")
    иначе
        Консоль.Записать("Доступ запрещён")
    ;
;
```

**ДЗ-2 (знак числа).** `если N > 0 ... иначеесли N < 0 ... иначе Ноль`.

**ДЗ-3 (светофор).** Цепочка `если/иначеесли` по строкам
`"красный"/"жёлтый"/"зелёный"` и финальное `иначе` для прочего ввода.

**ДЗ-4 (високосный, упрощённо).**
```
если Год % 4 = 0 тогда
    Консоль.Записать("Високосный")
иначе
    Консоль.Записать("Обычный")
;
```
Поясните, что настоящее правило сложнее (исключения для веков), но для
тренировки условий упрощённого варианта достаточно.

## Типичные ошибки

- Забывают `;`, закрывающий блок `если`.
- Пишут `Оценка = 5` и боятся, что это присваивание — пояснить, что в
  условии это сравнение.
- В диапазоне пишут `7 <= Возраст <= 17` одной строкой — нужно через `и`:
  `Возраст >= 7 и Возраст <= 17`.
- В цепочке `иначеесли` дублируют проверки — напомнить, что выполняется
  только первая подходящая ветка.
