# Урок 6. Мини-проект

## «Умный калькулятор»

Собираем всё из модуля 1 в одну программу

---

# Что мы умеем после модуля 1

- выводить текст — `Консоль.Записать`
- хранить данные — `пер`, `знч`, типы
- спрашивать — `СчитатьСтроку`, `СчитатьЧисло`
- считать — `+ - * /`
- выбирать — `если / иначе`

Сегодня соберём всё это в **один проект**.

---

# Задача проекта

Сделать калькулятор, который:

1. спрашивает два числа;
2. спрашивает действие (`+`, `-`, `*`, `/`);
3. считает результат;
4. красиво выводит ответ;
5. защищается от деления на ноль.

---

# Шаг 1. Спросить данные

```
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Первое число: ")
    пер Б = Консоль.СчитатьЧисло("Второе число: ")
    пер Действие = Консоль.СчитатьСтроку("Действие (+ - * /): ")
;
```

Числа читаем как `Число`, действие — как `Строку`.

---

# Шаг 2. Выбрать действие

```
если Действие = "+" тогда
    пер Р = А + Б
    Консоль.Записать("Результат: $Р")
иначеесли Действие = "-" тогда
    пер Р = А - Б
    Консоль.Записать("Результат: $Р")
;
```

Для каждого действия — своя ветка.

---

# Шаг 3. Умножение и деление

```
иначеесли Действие = "*" тогда
    пер Р = А * Б
    Консоль.Записать("Результат: $Р")
иначеесли Действие = "/" тогда
    // здесь нужна защита от деления на ноль!
;
```

---

# Шаг 4. Защита от деления на ноль

На ноль делить нельзя. Проверим это:

```
иначеесли Действие = "/" тогда
    если Б = 0 тогда
        Консоль.Записать("На ноль делить нельзя!")
    иначе
        пер Р = А / Б
        Консоль.Записать("Результат: $Р")
    ;
;
```

---

# Шаг 5. Неизвестное действие

Если человек ввёл не `+ - * /`, скажем об этом:

```
иначе
    Консоль.Записать("Неизвестное действие")
;
```

Это последняя ветка `иначе` — «на все остальные случаи».

---

```
    если Действие = "+" тогда

    иначеесли Действие = "-" тогда

        Консоль.Записать("Неизвестное действие")

```

# Как улучшить (идеи)

- добавить действие «возведение в степень» или «остаток»;
- выводить пример целиком: `5 + 3 = 8`;
- спрашивать, повторить ли расчёт (понадобятся циклы — модуль 2);
- проверять, что введено корректное действие, до вычислений.
