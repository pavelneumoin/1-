# Умный <span class="accent">калькулятор</span>

## Собираем всё из модуля 1 в одну программу

Ввод, переменные, арифметика и условия — вместе, в деле.

---

<!-- kicker: Что умеем -->

# Твой арсенал после модуля 1

- выводить текст — `Консоль.Записать`;
- хранить данные — `пер`, `знч`, типы;
- спрашивать — `СчитатьСтроку`, `СчитатьЧисло`;
- считать — `+ - * /`;
- выбирать — `если / иначе`.

Сегодня соберём из этого настоящий **проект**.

---

<!-- kicker: Задача -->

# Что должен уметь калькулятор

1. спросить два числа;
2. спросить действие (`+`, `-`, `*`, `/`);
3. посчитать результат;
4. красиво вывести ответ;
5. не сломаться при делении на ноль.

---

<!-- kicker: Шаг 1 -->

# Спрашиваем данные

```eos
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Первое число: ")
    пер Б = Консоль.СчитатьЧисло("Второе число: ")
    пер Действие = Консоль.СчитатьСтроку("Действие (+ - * /): ")
;
```

Числа читаем как `Число`, а действие — как `Строку`.

---

<!-- kicker: Шаг 2 -->

# Выбираем действие

```eos
если Действие = "+" тогда
    Консоль.Записать("Результат: " + (А + Б))
иначеесли Действие = "-" тогда
    Консоль.Записать("Результат: " + (А - Б))
иначеесли Действие = "*" тогда
    Консоль.Записать("Результат: " + (А * Б))
;
```

Для каждого действия — своя ветка.

---

<!-- kicker: Шаг 3 -->

# Деление и защита от нуля

На ноль делить нельзя — проверим это **до** деления:

```eos
иначеесли Действие = "/" тогда
    если Б = 0 тогда
        Консоль.Записать("На ноль делить нельзя!")
    иначе
        Консоль.Записать("Результат: " + (А / Б))
    ;
;
```

---

<!-- kicker: Ловушка -->

# Порядок проверки важен

<div class="callout warn"><span class="lead">Типичная ошибка</span>
Сначала делят, а потом проверяют ноль — поздно! Проверка <code>Б = 0</code>
должна стоять <strong>раньше</strong> вычисления <code>А / Б</code>.</div>

И последняя ветка — на всё остальное:

```eos
иначе
    Консоль.Записать("Неизвестное действие")
;
```

---

# Собираем программу

```eos
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Первое число: ")
    пер Б = Консоль.СчитатьЧисло("Второе число: ")
    пер Действие = Консоль.СчитатьСтроку("Действие: ")
    если Действие = "+" тогда
        Консоль.Записать("Результат: " + (А + Б))
    иначеесли Действие = "*" тогда
        Консоль.Записать("Результат: " + (А * Б))
    иначеесли Действие = "/" тогда
        если Б = 0 тогда
            Консоль.Записать("На ноль делить нельзя!")
        иначе
            Консоль.Записать("Результат: " + (А / Б))
        ;
    иначе
        Консоль.Записать("Неизвестное действие")
    ;
;
```

<!-- kicker: Прокачай -->

# Как сделать круче

- добавить действие «остаток» или «степень»;
- выводить пример целиком: `5 + 3 = 8`;
- спросить имя и поздороваться с игроком;
- спросить, повторить ли расчёт (это уже циклы — модуль 2).
