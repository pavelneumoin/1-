# Урок 6. Решения (для преподавателя) — Проект «Умный калькулятор»

Цель: ученик самостоятельно собирает программу из всех тем модуля 1
(ввод, переменные, арифметика, условия) и доводит её до рабочего вида.

Это проектный урок: ценится не только правильный код, но и то, что ученик
сам прошёл путь сборки и протестировал программу.

---

## Часть 1 ⭐ — базовая версия

```
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Первое число: ")
    пер Б = Консоль.СчитатьЧисло("Второе число: ")
    пер Действие = Консоль.СчитатьСтроку("Действие (+ или -): ")

    если Действие = "+" тогда
        Консоль.Записать("Результат: " + (А + Б))
    иначеесли Действие = "-" тогда
        Консоль.Записать("Результат: " + (А - Б))
    ;
;
```

---

## Часть 2–3 ⭐⭐ — полная версия

```
метод Скрипт()
    Консоль.Записать("=== Калькулятор ===")
    пер А = Консоль.СчитатьЧисло("Первое число: ")
    пер Б = Консоль.СчитатьЧисло("Второе число: ")
    пер Действие = Консоль.СчитатьСтроку("Действие (+ - * /): ")

    если Действие = "+" тогда
        Консоль.Записать("Результат: " + (А + Б))
    иначеесли Действие = "-" тогда
        Консоль.Записать("Результат: " + (А - Б))
    иначеесли Действие = "*" тогда
        Консоль.Записать("Результат: " + (А * Б))
    иначеесли Действие = "/" тогда
        если Б = 0 тогда
            Консоль.Записать("На ноль делить нельзя!")
        иначе
            Консоль.Записать("Результат: " + (А / Б))
        ;
    иначе
        Консоль.Записать("Неизвестное действие")
    ;
;
```

Обязательно протестировать вместе:
- `10 / 0` → сообщение про ноль;
- `2 ? 3` → «Неизвестное действие».

## Часть 4 ⭐⭐⭐ — красивый вывод

Пример для сложения (аналогично для остальных):

```
если Действие = "+" тогда
    пер Р = А + Б
    Консоль.Записать("$А + $Б = $Р")
;
```

## Часть 5 ⭐⭐⭐ — пятое действие

Пример: среднее двух чисел.

```
иначеесли Действие = "avg" тогда
    Консоль.Записать("Среднее: " + ((А + Б) / 2))
;
```

Пример: большее из двух.

```
иначеесли Действие = "max" тогда
    если А > Б тогда
        Консоль.Записать("Больше: $А")
    иначе
        Консоль.Записать("Больше: $Б")
    ;
;
```

## Типичные трудности

- Порядок веток `иначеесли` — забывают `иначе` в конце.
- Деление на ноль проверяют **после** деления, а не до — разобрать, что
  проверка должна стоять раньше вычисления.
- При «красивом выводе» путаются со склейкой строки и числа — посоветовать
  подстановку `$`.
- Сравнивают действие без кавычек (`Действие = +`) — напомнить, что это
  строка: `Действие = "+"`.
