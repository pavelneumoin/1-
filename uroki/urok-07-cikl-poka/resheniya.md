# Урок 7. Решения (для преподавателя) — Цикл «Пока»

Цель урока: ученик понимает идею цикла, пишет `пока ... цикл ... ;` с
тремя частями (начало, условие, шаг), умеет считать и копить сумму,
распознаёт бесконечный цикл.

> Напоминание: в 1С:Элемент блоки (в т. ч. цикл) закрываются `;`,
> ключевые слова строчные.

---

## Классная работа

**З1.** Счёт 1..5.

**З2 (до 10).**
```
метод Скрипт()
    пер i = 1
    пока i <= 10 цикл
        Консоль.Записать(i)
        i = i + 1
    ;
;
```

**З3 (обратный отсчёт).**
```
метод Скрипт()
    пер i = 10
    пока i >= 1 цикл
        Консоль.Записать(i)
        i = i - 1
    ;
    Консоль.Записать("Поехали!")
;
```

**З4 (ошибка).** Причина — нет шага `i = i + 1`, счётчик не меняется,
условие всегда истинно → зависание. Исправление: добавить `i = i + 1`
в тело цикла.

**З5 (чётные).**
```
пер i = 2
пока i <= 20 цикл
    Консоль.Записать(i)
    i = i + 2
;
```

**З6 (сумма 1..10).**
```
пер i = 1
пер Сумма = 0
пока i <= 10 цикл
    Сумма = Сумма + i
    i = i + 1
;
Консоль.Записать("Сумма: $Сумма")   // 55
```

**З7 (таблица на 5).**
```
пер i = 1
пока i <= 10 цикл
    Консоль.Записать(i * 5)
    i = i + 1
;
```

**З8 (копилка, неделя).**
```
пер день = 1
пер Копилка = 0
пока день <= 7 цикл
    Копилка = Копилка + 30
    Консоль.Записать("День $день: $Копилка")
    день = день + 1
;
Консоль.Записать("Итого: $Копилка")   // 210
```

**Блиц:** 5) сумма 1..100 = 5050.

---

## Домашняя работа — ответы

**Часть А.** А4 → `1, 4, 9, 16`. А5 → `i` растёт вместо убывания, условие
`i > 0` всегда истинно → бесконечный цикл (нужно `i = i - 1`).

**Часть Б.**
- Б1 — счёт 5..1 + `Старт!`.
- Б2 — `i = 2; i = i + 2` до 30.
- Б3 — `i = 1; i = i + 2` до 19.
- Б4 — сумма 1..20 = 210.
- Б5 — таблица на 7 (`i * 7`, i от 1 до 10).
- Б6 — копилка по 50 за 10 дней (итог 500).

**Часть В.**
- В1 (сумма чётных 1..100) = 2550.
- В2 (степени двойки):
```
пер n = 1
пока n <= 64 цикл
    Консоль.Записать(n)
    n = n * 2
;
```
- В3 — отсчёт с подписями + `Взлёт!`.
- В4 (шаги до 1000):
```
пер n = 1
пер шагов = 0
пока n <= 1000 цикл
    n = n * 3
    шагов = шагов + 1
;
Консоль.Записать("Шагов: $шагов")   // 7 (3^7 = 2187 > 1000)
```

---

## Типичные ошибки

- Забывают шаг (`i = i + 1`) → бесконечный цикл. Главная тема урока.
- Ставят шаг до вывода и получают сдвиг на 1 — разобрать порядок строк.
- Объявляют счётчик внутри цикла (`пер i` каждый раз) — он должен быть
  объявлен **до** цикла, меняться — внутри.
- Путают `<=` и `<` — выводят на одно число меньше/больше.
