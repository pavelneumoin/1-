# Короткий путь — цикл <span class="accent">«Для»</span>

## Когда известно, сколько раз повторять

Тот же результат, что у «Пока», но в два раза меньше кода.

---

<!-- kicker: Вспомним -->

# Как было с «Пока»

Чтобы посчитать от 1 до 5, мы писали три части:

```eos
пер i = 1            // начало
пока i <= 5 цикл     // условие
    Консоль.Записать(i)
    i = i + 1        // шаг
;
```

Работает. Но часто это можно записать короче.

---

<!-- kicker: Знакомься -->

# Цикл «Для»

```eos
для i = 1 по 5 цикл
    Консоль.Записать(i)
;
```

```out
1
2
3
4
5
```

Тот же результат — в три строки вместо пяти.

---

<!-- kicker: В чём фишка -->

# Счётчик работает сам

```eos
для i = 1 по 5 цикл
    ...
;
```

- счётчик `i` **создаётся сам**;
- идёт от `1` до `5`;
- после каждого круга **сам увеличивается на 1**.

<div class="callout tip"><span class="lead">Бонус</span>
Не нужно писать <code>i = i + 1</code> — а значит, бесконечный цикл тут
почти невозможен. «Для» сложнее сломать.</div>

---

<!-- kicker: Сравнение -->

# «Для» против «Пока»

| Бери «Для» | Бери «Пока» |
|------------|-------------|
| знаешь число повторений | повторять до события |
| счёт от и до | пока вводят правильный ответ |
| таблицы, суммы N чисел | пока хватает денег |

Оба нужны — выбирай под задачу.

---

<!-- kicker: Счётчик в деле -->

# Таблица умножения на 9

```eos
метод Скрипт()
    для i = 1 по 10 цикл
        Консоль.Записать("9 * $i = " + (9 * i))
    ;
;
```

```out
9 * 1 = 9
9 * 2 = 18
...
9 * 10 = 90
```

Счётчик `i` можно использовать прямо в вычислениях.

# Что выведет программа?

```eos
метод Скрипт()
    пер Сумма = 0
    для i = 1 по 100 цикл
        Сумма = Сумма + i
    ;
    Консоль.Записать(Сумма)
;
```

<div class="callout quiz"><span class="lead">Догадка дороже ответа</span>
Раньше сложить 100 чисел было тяжело. Сколько получится теперь?</div>

<!-- kicker: Важно про среду -->

# Если среда поправит «Для»

<div class="callout warn"><span class="lead">Внимание</span>
Точная запись заголовка «Для» может чуть отличаться в твоей версии
1С:Элемент. Подсветит ошибку — глянь подсказку автодополнения: смысл один
и тот же (счётчик от начала до конца).</div>

А цикл «Пока» работает везде одинаково — на него всегда можно опереться.

# Слабо нарисовать лесенку?

Используя цикл, выведи лесенку из звёздочек:

```out
*
**
***
****
*****
```

<div class="callout"><span class="lead">Подсказка</span>
Заведи строку <code>пер строка = ""</code> и на каждом круге добавляй к ней
ещё одну <code>*</code>, затем выводи строку.</div>

<!-- kicker: Итоги -->

# Что мы узнали

- «Для» — короткий цикл, когда известно число повторений;
- `для i = 1 по 5 цикл ... ;` — счётчик создаётся и растёт сам;
- счётчик можно использовать в формулах (`i * 9`);
- «Для» — для счёта, «Пока» — для повторения до события.
