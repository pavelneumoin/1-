# Урок 8. Цикл «Для»

## Программирование на 1С:Элемент

Короткий способ повторять заданное число раз

---

# Вспомним «Пока»

Чтобы посчитать от 1 до 5, мы писали три части:

```
пер i = 1            // начало
пока i <= 5 цикл     // условие
    Консоль.Записать(i)
    i = i + 1        // шаг
;
```

Это работает, но часто можно записать **короче**.

---

# Знакомьтесь: цикл «Для»

Когда заранее известно, **сколько раз** повторять, удобнее «Для»:

```
для i = 1 по 5 цикл
    Консоль.Записать(i)
;
```

Вывод:

```
1
2
3
4
5
```

---

# В чём удобство

```
для i = 1 по 5 цикл
    ...
;
```

- счётчик `i` **создаётся сам**;
- начинается с `1`, доходит до `5`;
- после каждого повторения **сам увеличивается на 1**.

Не нужно писать `i = i + 1` — за нас это делает цикл.

---

# «Пока» и «Для» — сравнение

Одна и та же задача (1..5):

```
// Пока                      // Для
пер i = 1                    для i = 1 по 5 цикл
пока i <= 5 цикл                 Консоль.Записать(i)
    Консоль.Записать(i)      ;
    i = i + 1
;
```

«Для» короче и его сложнее «сломать» (бесконечный цикл почти исключён).

---

# Можно считать с любого числа

```
для i = 3 по 7 цикл
    Консоль.Записать(i)
;
```

Вывод: `3 4 5 6 7`.

Границы задаём сами: `для i = <начало> по <конец>`.

---

# Используем счётчик в вычислениях

Таблица умножения на 9:

```
метод Скрипт()
    для i = 1 по 10 цикл
        Консоль.Записать("9 * $i = " + (9 * i))
    ;
;
```

Вывод: `9 * 1 = 9`, `9 * 2 = 18`, … `9 * 10 = 90`.

---

# Накопление работает так же

Сумма от 1 до 100 — раньше было сложно, теперь легко:

```
метод Скрипт()
    пер Сумма = 0
    для i = 1 по 100 цикл
        Сумма = Сумма + i
    ;
    Консоль.Записать("Сумма: $Сумма")   // 5050
;
```

---

# Когда «Для», а когда «Пока»

| Бери «Для» | Бери «Пока» |
|------------|-------------|
| знаешь число повторений | повторять до события |
| счёт от и до | пока вводят правильный ответ |
| таблицы, суммы N чисел | пока хватает денег |

Оба цикла нужны — выбирай по задаче.

---

# Важно про среду

Точная запись заголовка «Для» может чуть отличаться в твоей версии
1С:Элемент. Если среда подчеркнёт строку — посмотри подсказку
автодополнения: **смысл** один и тот же (счётчик от начала до конца),
меняется только запись.

А цикл «Пока» работает везде одинаково — на него всегда можно опереться.

---

# Что мы узнали

- «Для» — короткий цикл, когда известно число повторений.
- `для i = 1 по 5 цикл ... ;` — счётчик создаётся и растёт сам.
- Счётчик можно использовать в вычислениях (`i * 9`).
- «Для» — для счёта, «Пока» — для повторения до события.
