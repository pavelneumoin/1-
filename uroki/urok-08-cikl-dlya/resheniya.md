# Урок 8. Решения (для преподавателя) — Цикл «Для»

Цель урока: ученик пишет счётный цикл `для i = 1 по N цикл ... ;`,
понимает, что счётчик создаётся и растёт сам, использует его в формулах,
выбирает между «Для» и «Пока».

> **Важно про синтаксис.** Точная форма заголовка «Для» может отличаться в
> конкретной версии 1С:Элемент (например, запись границ). Если среда
> подсветит ошибку — посмотрите автодополнение; идея одна. Любую из этих
> задач всегда можно решить и циклом «Пока» (урок 7), который мы знаем
> точно. Если в вашей версии «Для» считает только по возрастанию —
> используйте «Пока» для обратного счёта.

---

## Классная работа

**З1 (1..6).**
```
для i = 1 по 6 цикл
    Консоль.Записать(i)
;
```

**З2 (5..15).** Аналогично, `для i = 5 по 15 цикл`.

**З3 (перепись на «Для»).**
```
для i = 1 по 8 цикл
    Консоль.Записать(i)
;
```

**З4 (таблица на 6).**
```
для i = 1 по 10 цикл
    Консоль.Записать("6 * $i = " + (6 * i))
;
```

**З5 (сумма 1..50).**
```
пер Сумма = 0
для i = 1 по 50 цикл
    Сумма = Сумма + i
;
Консоль.Записать("Сумма: $Сумма")   // 1275
```

**З6 (квадраты).** `Консоль.Записать(i * i)` для i от 1 до 10.

**З7 (лесенка из звёзд).**
```
пер строка = ""
для i = 1 по 5 цикл
    строка = строка + "*"
    Консоль.Записать(строка)
;
```

**З8 (сколько чётных 1..30).**
```
пер счёт = 0
для i = 1 по 30 цикл
    если i % 2 = 0 тогда
        счёт = счёт + 1
    ;
;
Консоль.Записать("Чётных: $счёт")   // 15
```
(Если `%` недоступен — посчитать «Пока» с шагом 2 либо найти аналог.)

---

## Домашняя работа — ответы

**Часть А.** А4 → `2, 4, 6, 8, 10`. А5 → `для i = 1 по 6 цикл ... ;`.

**Часть Б.**
- Б1 — таблица на 8 (`8 * i`).
- Б2 — сумма 1..100 = 5050.
- Б3 — квадраты 1..12.
- Б4 — обратный счёт; при необходимости через «Пока» (`i = 20; i = i - 1`).
- Б5 — делятся на 5: считаем `если i % 5 = 0` → 20 чисел.
- Б6 — сумма 1..N и `Сумма / N`.

**Часть В.**
- В1 (пирамидка) — копим строку из `#`, как в З7.
- В2 (факториал):
```
пер П = 1
для i = 1 по 5 цикл
    П = П * i
;
Консоль.Записать(П)   // 120
```
- В3 (сумма кубов) = 225.
- В4 (сетка) — введение во вложенные циклы; для слабых групп допустимо
  вывести вручную, для сильных — цикл в цикле.

---

## Типичные ошибки

- Внутри «Для» пишут ещё и `i = i + 1` — счётчик меняется дважды,
  половина значений пропадает. Подчеркнуть: в «Для» шаг автоматический.
- Путают, когда брать «Для», а когда «Пока» — вернуться к таблице сравнения.
- При накоплении забывают объявить `Сумма = 0` до цикла.
