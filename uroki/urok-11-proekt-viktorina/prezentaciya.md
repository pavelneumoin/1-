# Викторина-<span class="accent">тренажёр</span>

## Собираем циклы и условия в одну программу

Программа, которая сама задаёт вопросы и считает твои очки.

---

<!-- kicker: Арсенал -->

# Что мы умеем после циклов

- повторять действия — `пока` и `для`;
- считать и копить — счётчики и суммы;
- принимать решения — `если / иначе`;
- общаться — `СчитатьЧисло`, `Консоль.Записать`.

Сегодня соберём из этого настоящую **викторину**.

---

<!-- kicker: Задача -->

# Что должна уметь программа

1. задать **5 вопросов** подряд (в цикле);
2. на каждый дождаться ответа;
3. проверить — верно или нет;
4. посчитать **очки**;
5. в конце показать счёт и оценку.

---

<!-- kicker: Шаг 1 -->

# Заготовка

```eos
метод Скрипт()
    пер Очки = 0
    Консоль.Записать("=== Викторина: умножение на 3 ===")
    для i = 1 по 5 цикл
        // здесь будет вопрос
    ;
;
```

<div class="callout warn"><span class="lead">Важно</span>
<code>Очки</code> заводим <strong>до</strong> цикла. Заведёшь внутри — они
будут обнуляться на каждом вопросе.</div>

---

<!-- kicker: Шаг 2 -->

# Задаём вопрос из счётчика

```eos
для i = 1 по 5 цикл
    пер Правильный = i * 3
    пер Ответ = Консоль.СчитатьЧисло("Сколько будет $i * 3? ")
;
```

На круге `i = 1` спросим про `1 * 3`, на `i = 2` — про `2 * 3`, и так далее.
Один цикл — пять разных вопросов.

---

<!-- kicker: Шаг 3 -->

# Проверяем ответ

```eos
если Ответ = Правильный тогда
    Консоль.Записать("Верно!")
    Очки = Очки + 1
иначе
    Консоль.Записать("Неверно. Правильно: $Правильный")
;
```

Верный ответ — плюс очко. Неверный — подскажем правильный.

---

<!-- kicker: Шаг 4 -->

# Итог и оценка

```eos
Консоль.Записать("Счёт: $Очки из 5")
если Очки = 5 тогда
    Консоль.Записать("Отлично! Ты чемпион!")
иначеесли Очки >= 3 тогда
    Консоль.Записать("Хорошо, но можно лучше")
иначе
    Консоль.Записать("Потренируйся ещё")
;
```

# Собираем программу

```eos
метод Скрипт()
    пер Очки = 0
    для i = 1 по 5 цикл
        пер Правильный = i * 3
        пер Ответ = Консоль.СчитатьЧисло("Сколько будет $i * 3? ")
        если Ответ = Правильный тогда
            Консоль.Записать("Верно!")
            Очки = Очки + 1
        иначе
            Консоль.Записать("Неверно. Правильно: $Правильный")
        ;
    ;
    Консоль.Записать("Счёт: $Очки из 5")
;
```
