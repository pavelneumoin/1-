# Урок 11. Мини-проект

## «Викторина-тренажёр»

Собираем циклы и условия в одну программу

---

# Что мы умеем после циклов

- повторять действия — `пока` и `для`;
- считать и копить — счётчики и суммы;
- принимать решения — `если / иначе`;
- общаться — `СчитатьЧисло`, `Консоль.Записать`.

Сегодня соберём из этого **викторину**, которая сама задаёт вопросы.

---

# Задача проекта

Программа-тренажёр по умножению:

1. задаёт **5 вопросов** подряд (в цикле);
2. на каждый ждёт ответ;
3. проверяет — верно или нет;
4. считает **очки**;
5. в конце выводит счёт и оценку.

---

# Шаг 1. Заготовка

```
метод Скрипт()
    пер Очки = 0
    Консоль.Записать("=== Викторина: умножение на 3 ===")

    для i = 1 по 5 цикл
        // здесь будет вопрос
    ;

    Консоль.Записать("Конец")
;
```

Очки заводим **до** цикла, иначе они будут обнуляться каждый раз.

---

# Шаг 2. Задаём вопрос

Вопрос построим из счётчика `i`:

```
для i = 1 по 5 цикл
    пер Правильный = i * 3
    пер Ответ = Консоль.СчитатьЧисло("Сколько будет $i * 3? ")
    ...
;
```

На повторении `i = 1` спросим про `1 * 3`, на `i = 2` — про `2 * 3`, и т. д.

---

# Шаг 3. Проверяем ответ

```
для i = 1 по 5 цикл
    пер Правильный = i * 3
    пер Ответ = Консоль.СчитатьЧисло("Сколько будет $i * 3? ")
    если Ответ = Правильный тогда
        Консоль.Записать("Верно!")
        Очки = Очки + 1
    иначе
        Консоль.Записать("Неверно. Правильно: $Правильный")
    ;
;
```

---

# Шаг 4. Итог и оценка

После цикла подводим результат:

```
Консоль.Записать("Твой счёт: $Очки из 5")

если Очки = 5 тогда
    Консоль.Записать("Отлично! Ты чемпион!")
иначеесли Очки >= 3 тогда
    Консоль.Записать("Хорошо, но можно лучше")
иначе
    Консоль.Записать("Потренируйся ещё")
;
```

---

# Собираем целиком

```
метод Скрипт()
    пер Очки = 0
    Консоль.Записать("=== Викторина: умножение на 3 ===")
    для i = 1 по 5 цикл
        пер Правильный = i * 3
        пер Ответ = Консоль.СчитатьЧисло("Сколько будет $i * 3? ")
        если Ответ = Правильный тогда
            Консоль.Записать("Верно!")
            Очки = Очки + 1
        иначе
            Консоль.Записать("Неверно. Правильно: $Правильный")
        ;
    ;
    Консоль.Записать("Счёт: $Очки из 5")
;
```

---

# Как улучшить (идеи)

- сделать **10** вопросов вместо 5;
- тренировать не умножение, а сложение или квадраты;
- считать не только верные, но и **ошибки**;
- спросить имя игрока и поздравить по имени;
- спросить, на какое число тренироваться, и подставить его.

---

# Почему это важно

Ты только что собрал программу, которая:

- **повторяет** (цикл),
- **общается** (ввод-вывод),
- **проверяет** (условие),
- **запоминает результат** (счётчик).

Это и есть основа почти любой игры и приложения.
