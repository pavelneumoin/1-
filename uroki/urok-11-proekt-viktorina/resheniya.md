# Урок 11. Решения (для преподавателя) — Проект «Викторина-тренажёр»

Цель: ученик самостоятельно собирает программу из циклов, условий, ввода
и счётчиков — без новых конструкций. Проектный урок: ценится доведение до
рабочего состояния и тестирование.

Весь код урока использует только проверенные конструкции (`для`/`пока`,
`если`, `Консоль.Записать/СчитатьЧисло`) — массивы здесь не нужны.

---

## Часть 1 ⭐ — один вопрос

```
метод Скрипт()
    пер Ответ = Консоль.СчитатьЧисло("Сколько будет 7 * 8? ")
    если Ответ = 56 тогда
        Консоль.Записать("Верно!")
    иначе
        Консоль.Записать("Неверно. Правильно: 56")
    ;
;
```

---

## Часть 2–3 ⭐⭐ — полная викторина

```
метод Скрипт()
    пер Очки = 0
    Консоль.Записать("=== Викторина: умножение на 3 ===")
    для i = 1 по 5 цикл
        пер Правильный = i * 3
        пер Ответ = Консоль.СчитатьЧисло("Сколько будет $i * 3? ")
        если Ответ = Правильный тогда
            Консоль.Записать("Верно!")
            Очки = Очки + 1
        иначе
            Консоль.Записать("Неверно. Правильно: $Правильный")
        ;
    ;
    Консоль.Записать("Счёт: $Очки из 5")
    если Очки = 5 тогда
        Консоль.Записать("Отлично! Ты чемпион!")
    иначеесли Очки >= 3 тогда
        Консоль.Записать("Хорошо, но можно лучше")
    иначе
        Консоль.Записать("Потренируйся ещё")
    ;
;
```

Тестировать: все верно → `5 из 5` + «чемпион»; часть неверно → меньший счёт.

---

## Часть 4 ⭐⭐⭐ — улучшения

- **A (ошибки):** завести `пер Ошибок = 0`, в ветке `иначе` —
  `Ошибок = Ошибок + 1`; в конце вывести оба числа.
- **B (имя):** `пер Имя = Консоль.СчитатьСтроку(...)`, в конце
  `"$Имя, твой счёт: $Очки"`.
- **C (своё число):** `пер N = Консоль.СчитатьЧисло("На какое число? ")`,
  вопрос `i * N`, правильный `i * N`.
- **D (10 вопросов):** `для i = 1 по 10 цикл`, в конце `из 10`.

---

## Домашняя работа — ответы

**Часть А.** А2 — счётчик `Ошибок` параллельно `Очки`.

**Часть Б.**
- Б1/Б2/Б3 — та же структура, меняется формула вопроса (`i + 10`, `i * i`,
  `i * N`).
- Б4 (угадайка): загадка в коде, цикл из 3 попыток; при совпадении вывести
  `Угадал!`. Полноценный «выход из цикла» (оператор прерывания) будет позже —
  пока достаточно довести цикл до конца, перестав менять результат.

**Часть В.**
- В1 — оценка в процентах `Очки * 10`.
- В2 — два цикла подряд, отдельные счётчики + сумма.
- В3 — имя + сравнение счёта с числом-рекордом через `если`.

## Типичные трудности

- `пер Очки = 0` объявляют **внутри** цикла — счёт каждый раз обнуляется.
  Объявлять до цикла.
- Сравнивают `Ответ = Правильный` и боятся, что это присваивание —
  напомнить про контекст условия.
- Забывают `;`, закрывающий `если` внутри цикла, и `;`, закрывающий цикл —
  получается «лесенка» из незакрытых блоков. Разобрать вложенность.
