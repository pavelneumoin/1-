<!-- kicker: Урок 12 -->

# Своя <span class="accent">команда</span>

## Методы в 1С:Элемент

Научимся создавать собственные команды и вызывать их одним словом.

---

<!-- kicker: Проблема -->

# Один и тот же код снова и снова

Представь, что в трёх местах программы нужно вывести красивую шапку:

```eos
Консоль.Записать("============")
Консоль.Записать("   МЕНЮ")
Консоль.Записать("============")
```

Копировать эти три строки повсюду? А если захочешь изменить — править везде?

---

<!-- kicker: Идея -->

# Заверни код в метод

**Метод** — это твоя собственная команда: даёшь куску кода имя и вызываешь
его, когда нужно.

<div class="callout fun"><span class="lead">Образ</span>
Метод — как кнопка «сделать бутерброд». Нажал — получил результат,
не повторяя рецепт каждый раз.</div>

---

<!-- kicker: Создаём -->

# Объявляем метод

```eos
метод Шапка()
    Консоль.Записать("============")
    Консоль.Записать("   МЕНЮ")
    Консоль.Записать("============")
;
```

- `метод` — создаём новую команду;
- `Шапка` — имя (придумываем сами);
- `()` — пока пустые скобки;
- тело и `;` в конце — как обычно.

---

<!-- kicker: Вызываем -->

# Вызываем по имени

Метод сам по себе не выполнится — его нужно **вызвать** из `Скрипт`:

```eos
метод Шапка()
    Консоль.Записать("============")
    Консоль.Записать("   МЕНЮ")
    Консоль.Записать("============")
;

метод Скрипт()
    Шапка()
    Консоль.Записать("Привет!")
    Шапка()
;
```

---

<!-- kicker: Результат -->

# Один метод — много вызовов

```out
============
   МЕНЮ
============
Привет!
============
   МЕНЮ
============
```

Написали шапку один раз — вызвали дважды. Меньше кода, меньше ошибок.

---

<!-- kicker: Лайфхак -->

# Главное правило хорошего кода

<div class="callout tip"><span class="lead">Не повторяйся</span>
Если копируешь один и тот же код — заверни его в метод. Тогда изменить
нужно будет только в одном месте, а не в десяти.</div>

Профи называют это правилом DRY — «не повторяй себя».

# Сколько строк выведет программа?

```eos
метод Привет()
    Консоль.Записать("Привет!")
;

метод Скрипт()
    Привет()
    Привет()
    Привет()
;
```

<div class="callout quiz"><span class="lead">Посчитай вызовы</span>
Сколько раз вызвали метод — столько раз он и сработает.</div>

---

<!-- kicker: Где какой -->

# `Скрипт` — тоже метод

Заметил? `Скрипт` — это обычный метод, просто с особым именем:
с него программа **начинает** работу.

```eos
метод Скрипт()    // отсюда всё стартует
    ...
;
```

Остальные методы выполняются, только когда их вызовут.

# Слабо сделать «рамку»?

Создай метод `Линия()`, который выводит строку из 20 чёрточек, и вызови
его до и после своего имени:

```out
--------------------
Меня зовут Бит
--------------------
```

<div class="callout"><span class="lead">Подсказка</span>
Один <code>Консоль.Записать("--------------------")</code> внутри метода —
и вызывай его дважды.</div>

<!-- kicker: Итоги -->

# Что мы узнали

- метод — это своя команда: имя + код;
- `метод Имя() ... ;` — объявление;
- `Имя()` — вызов (можно сколько угодно раз);
- `Скрипт` — особый метод, точка старта;
- не повторяй код — заворачивай в метод (DRY).
