# Урок 12. Решения (для преподавателя) — Методы

Цель урока: ученик объявляет собственный метод (`метод Имя() ... ;`),
вызывает его из `Скрипт`, понимает идею «не повторяй код» (DRY).

---

## Классная работа

**З1.**
```
метод Привет()
    Консоль.Записать("Привет!")
;
метод Скрипт()
    Привет()
;
```

**З2.** Три вызова → три строки `Привет!`.

**З3 (Линия).**
```
метод Линия()
    Консоль.Записать("--------------------")
;
метод Скрипт()
    Линия()
    Консоль.Записать("Меня зовут Бит")
    Линия()
;
```

**З4 (Шапка).**
```
метод Шапка()
    Консоль.Записать("======")
    Консоль.Записать(" МЕНЮ")
    Консоль.Записать("======")
;
метод Скрипт()
    Шапка()
    Шапка()
;
```

**З5 (ошибка).** Метод `Привет` объявлен, но в `Скрипт` его не вызвали —
значит, он не выполнится. Нужно добавить `Привет()` внутрь `Скрипт`.

**З6 (узор).**
```
метод Звезда()
    Консоль.Записать("*****")
;
метод Точки()
    Консоль.Записать(".....")
;
метод Скрипт()
    Звезда()
    Точки()
    Звезда()
    Точки()
;
```

---

## Домашняя работа — ответы

**Часть А.** А4 → три строки `эй`.

**Часть Б.** Б1–Б3 — методы выводят свои строки, вызываются нужное число
раз. Б4 — метод объявлен, но не вызван; добавить `Привет()` в `Скрипт`.

**Часть В.** В1 — три метода-«полосы», вызванные по очереди, дают флаг.
В2/В3 — любой осмысленный узор/логотип; оцениваем, что код вынесен в
методы и вызывается.

---

## Типичные ошибки

- Объявляют метод, но забывают вызвать его в `Скрипт` — ничего не выводится.
- Забывают `;` в конце метода → «не закрыт блок».
- Пишут код вызова до объявления и думают, что важен порядок, — в одном
  файле порядок объявления методов значения не имеет, точка входа — `Скрипт`.
- Путают объявление `метод Имя()` и вызов `Имя()` (без слова `метод`).
