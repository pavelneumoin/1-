## Часть Б. Основные задачи ⭐⭐

**Б1. Площадь и периметр.** Два метода: `Площадь(а, б)` и `Периметр(а, б)`.
Выведи оба для прямоугольника 6×4.

**Б2. Максимум.** Метод `Максимум(А, Б): Число`. Проверь на трёх парах.

**Б3. Минимум.** Метод `Минимум(А, Б): Число` (возвращает меньшее).

**Б4. Среднее.** Метод `Среднее(А, Б): Число` возвращает `(А + Б) / 2`.
Выведи среднее двух введённых чисел.

**Б5. Скидка.** Метод `СоСкидкой(Цена: Число): Число` возвращает цену
минус 10% (`Цена - Цена / 10`). Выведи для цены 500.
