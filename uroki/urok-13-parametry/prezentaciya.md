# Методы, которые <span class="accent">принимают и отдают</span>

## Параметры и возвращаемые значения

Сделаем методы по-настоящему полезными: передадим им данные и заберём ответ.

---

<!-- kicker: Вспомним -->

# Пока метод делал одно и то же

```eos
метод Привет()
    Консоль.Записать("Привет, Аня!")
;
```

Этот метод всегда здоровается только с Аней. А хочется — с любым именем.

---

<!-- kicker: Параметры -->

# Передаём данные в метод

В скобках указываем **параметр** — данные, которые метод получит:

```eos
метод Привет(Имя: Строка)
    Консоль.Записать("Привет, $Имя!")
;

метод Скрипт()
    Привет("Аня")
    Привет("Бит")
;
```

```out
Привет, Аня!
Привет, Бит!
```

---

<!-- kicker: Несколько -->

# Параметров может быть несколько

```eos
метод Сумма(А: Число, Б: Число)
    Консоль.Записать("Итог: " + (А + Б))
;

метод Скрипт()
    Сумма(2, 3)      // Итог: 5
    Сумма(10, 7)     // Итог: 17
;
```

Параметры перечисляем через запятую, у каждого — свой тип.

---

<!-- kicker: Возврат -->

# Метод может вернуть ответ

Если указать тип после `:`, метод **вернёт значение** через `возврат`:

```eos
метод Сумма(А: Число, Б: Число): Число
    возврат А + Б
;

метод Скрипт()
    пер Р = Сумма(3, 5)
    Консоль.Записать("3 + 5 = $Р")   // 3 + 5 = 8
;
```

---

<!-- kicker: Разница -->

# Два вида методов

| Вид | Есть тип после `:`? | Что делает |
|-----|---------------------|------------|
| «делатель» | нет | просто выполняет действия |
| «считатель» | да, есть `возврат` | возвращает значение-ответ |

<div class="callout tip"><span class="lead">Запомни</span>
Указал тип результата — значит, внутри обязательно должен быть
<code>возврат</code>.</div>

---

<!-- kicker: Сила -->

# Ответ можно использовать дальше

Возвращённое значение — обычное число, с ним можно считать:

```eos
метод Площадь(Ш: Число, В: Число): Число
    возврат Ш * В
;

метод Скрипт()
    пер Общая = Площадь(3, 4) + Площадь(5, 2)
    Консоль.Записать("Всего: $Общая")   // 22
;
```

# Что выведет программа?

```eos
метод Удвоить(N: Число): Число
    возврат N * 2
;

метод Скрипт()
    пер X = Удвоить(5)
    пер Y = Удвоить(X)
    Консоль.Записать(Y)
;
```

<div class="callout quiz"><span class="lead">Иди по цепочке</span>
Сначала посчитай <code>X</code>, потом подставь его в <code>Удвоить</code>.</div>

# Слабо сделать метод «Максимум»?

Напиши метод `Максимум(А, Б): Число`, который возвращает большее из двух
чисел, и проверь его:

```out
Максимум 7 и 3 = 7
Максимум 4 и 9 = 9
```

<div class="callout"><span class="lead">Подсказка</span>
Внутри — <code>если А &gt; Б тогда возврат А иначе возврат Б ;</code>.</div>

<!-- kicker: Итоги -->

# Что мы узнали

- параметры в `()` — данные, которые получает метод;
- параметров может быть несколько, через запятую;
- тип после `:` + `возврат` — метод возвращает ответ;
- возвращённое значение можно использовать в вычислениях;
- метод без типа результата просто выполняет действия.
