# Урок 13. Решения (для преподавателя) — Параметры и возврат

Цель урока: ученик передаёт данные в метод через параметры и получает
ответ через `возврат`, различает метод-«делатель» и метод-«считатель»,
использует возвращённое значение в выражениях.

---

## Классная работа

**З1 (привет по имени).**
```
метод Привет(Имя: Строка)
    Консоль.Записать("Привет, $Имя!")
;
метод Скрипт()
    Привет("Аня")
    Привет("Бит")
;
```

**З2 (сумма).**
```
метод Сумма(А: Число, Б: Число): Число
    возврат А + Б
;
метод Скрипт()
    Консоль.Записать(Сумма(4, 6))   // 10
;
```

**З3 (площадь).** `возврат Ш * В`; вызвать для двух прямоугольников.

**З4 (удвоить).** `X = Удвоить(5) = 10`, `Y = Удвоить(10) = 20`. Ответ: **20**.

**З5 (максимум).**
```
метод Максимум(А: Число, Б: Число): Число
    если А > Б тогда
        возврат А
    иначе
        возврат Б
    ;
;
```

**З6 (сумма площадей).** `Площадь(3, 4) + Площадь(5, 2)` = 12 + 10 = **22**.

---

## Домашняя работа — ответы

**Часть А.** А4 → `Плюс10(5) = 15`, затем `Плюс10(15) = 25`. Ответ: **25**.

**Часть Б.**
- Б1 — `Площадь`=24, `Периметр`=20.
- Б2 — `Максимум` через `если/иначе`.
- Б3 — `Минимум` — то же, но возвращает меньшее.
- Б4 — `(А + Б) / 2`.
- Б5 — `Цена - Цена / 10` → для 500 = 450.

**Часть В.**
- В1 — `Куб(Сумма(1, 2))` = `Куб(3)` = 27.
- В2 — `Стоимость(Цена, Количество)` = `Цена * Количество`.
- В3 — три метода, три результата (11, 5, 24).

---

## Типичные ошибки

- Указали тип результата после `:`, но забыли `возврат` внутри.
- Пишут `возврат` в методе без типа результата.
- Вызывают метод, но не используют и не выводят возвращённое значение
  («посчитал и потерял»).
- Путают параметр (в объявлении) и аргумент (при вызове) — это нормально,
  показать на примере `Сумма(А, Б)` ↔ `Сумма(4, 6)`.
