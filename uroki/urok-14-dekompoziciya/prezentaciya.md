# Большую задачу — <span class="accent">на кусочки</span>

## Разбиваем программу на методы

Секрет программистов: сложное — это много простого, разложенного по полочкам.

---

<!-- kicker: Идея -->

# Как едят слона

Никто не пишет большую программу одной кучей. Её **делят на части**,
каждая часть — отдельный маленький метод, который делает одно дело.

<div class="callout fun"><span class="lead">Принцип</span>
Один метод — одно дело. Маленькие методы легко понять, проверить и
переиспользовать.</div>

---

<!-- kicker: Было -->

# Всё в одной куче

```eos
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Сторона А: ")
    пер Б = Консоль.СчитатьЧисло("Сторона Б: ")
    Консоль.Записать("Площадь: " + (А * Б))
    Консоль.Записать("Периметр: " + (2 * (А + Б)))
;
```

Работает, но всё свалено вместе. Разложим по методам.

---

<!-- kicker: Стало -->

# Каждое дело — свой метод

```eos
метод Площадь(А: Число, Б: Число): Число
    возврат А * Б
;

метод Периметр(А: Число, Б: Число): Число
    возврат 2 * (А + Б)
;

метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Сторона А: ")
    пер Б = Консоль.СчитатьЧисло("Сторона Б: ")
    Консоль.Записать("Площадь: " + Площадь(А, Б))
    Консоль.Записать("Периметр: " + Периметр(А, Б))
;
```

---

<!-- kicker: Почему лучше -->

# Чем это удобнее

- `Скрипт` читается как план: «посчитай площадь, посчитай периметр»;
- каждый метод можно проверить отдельно;
- `Площадь` пригодится и в другой программе;
- ошибку искать проще — она внутри одного маленького метода.

---

<!-- kicker: Методы зовут методы -->

# Метод может вызывать метод

```eos
метод Квадрат(N: Число): Число
    возврат N * N
;

метод СуммаКвадратов(А: Число, Б: Число): Число
    возврат Квадрат(А) + Квадрат(Б)
;

метод Скрипт()
    Консоль.Записать(СуммаКвадратов(3, 4))   // 25
;
```

Маленькие методы складываются в большие — как кубики.

---

<!-- kicker: Лайфхак -->

# Хорошее имя метода — глагол

<div class="callout tip"><span class="lead">Совет</span>
Имя метода должно говорить, что он делает: <code>ПосчитатьСумму</code>,
<code>Поздороваться</code>, <code>Площадь</code>. По имени должно быть
понятно без чтения кода.</div>

# Что вернёт `Финал(2)`?

```eos
метод Плюс1(N: Число): Число
    возврат N + 1
;

метод Финал(N: Число): Число
    возврат Плюс1(N) * Плюс1(N)
;
```

<div class="callout quiz"><span class="lead">По шагам</span>
Сначала посчитай <code>Плюс1(2)</code>, потом перемножь.</div>

<!-- class: content -->

# Слабо собрать из методов?

Сделай два метода и собери из них третий:

- `Площадь(а, б)` — площадь прямоугольника;
- `ЦенаПокраски(площадь)` — площадь × 50 (рублей за единицу);
- в `Скрипт` посчитай цену покраски стены 3 × 4.

<div class="callout"><span class="lead">Подсказка</span>
<code>ЦенаПокраски(Площадь(3, 4))</code> — метод внутри метода.</div>

- `Скрипт` читается как план программы;
- имя метода — глагол, говорящий о деле.
