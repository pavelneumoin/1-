# Урок 14. Решения (для преподавателя) — Разбиваем на методы

Цель урока: ученик делит задачу на маленькие методы, вызывает методы из
других методов, понимает пользу декомпозиции и хороших имён.

---

## Классная работа

**З1 (квадрат).** `возврат N * N`; `Квадрат(6)` = 36.

**З2 (сумма квадратов).**
```
метод СуммаКвадратов(А: Число, Б: Число): Число
    возврат Квадрат(А) + Квадрат(Б)
;
```
`СуммаКвадратов(3, 4)` = 9 + 16 = **25**.

**З3 (площадь и периметр).**
```
метод Площадь(А: Число, Б: Число): Число
    возврат А * Б
;
метод Периметр(А: Число, Б: Число): Число
    возврат 2 * (А + Б)
;
метод Скрипт()
    пер А = Консоль.СчитатьЧисло("Сторона А: ")
    пер Б = Консоль.СчитатьЧисло("Сторона Б: ")
    Консоль.Записать("Площадь: " + Площадь(А, Б))
    Консоль.Записать("Периметр: " + Периметр(А, Б))
;
```

**З4 (Финал(2)).** `Плюс1(2)` = 3, затем `3 * 3` = **9**.

**З5 (цена покраски).**
```
метод Площадь(А: Число, Б: Число): Число
    возврат А * Б
;
метод ЦенаПокраски(S: Число): Число
    возврат S * 50
;
метод Скрипт()
    Консоль.Записать(ЦенаПокраски(Площадь(3, 4)))   // 600
;
```

**З6 (имя).** Подходящее имя — `Среднее` (метод считает среднее двух чисел).

---

## Домашняя работа — ответы

**Часть А.** А4 → `Г(3)` = 5, затем `5 * 5` = **25**.

**Часть Б.** Б1 → 25. Б2 — два метода, оба вызваны. Б3 — `Среднее`
использует `Сумма`: `Сумма(а, б) / 2`. Б4 — хорошее имя `Стоимость`.

**Часть В.** В1 — `ЦенаПокраски(Площадь(4, 5))` = 1000. В2 —
`СоСкидкой(Стоимость(200, 3))` = `СоСкидкой(600)` = 540. В3 — оцениваем
осмысленную декомпозицию и понятные имена.

---

## Типичные ошибки

- Делают один огромный метод вместо нескольких маленьких — обсудить
  читаемость.
- Дублируют код, который можно вынести в общий метод.
- Дают методам невнятные имена (`Х`, `Метод1`) — вернуться к правилу
  «имя-глагол, говорящее о деле».
