# Когда что-то идёт <span class="accent">не так</span>

## Проверки и защита программы

Хорошая программа не падает от странных данных. Научим её быть осторожной.

---

<!-- kicker: Проблема -->

# Пользователь введёт что угодно

Ты ждёшь возраст — а введут `0`, `-5` или огромное число. Ждёшь делитель —
а введут ноль.

<div class="callout warn"><span class="lead">Реальность</span>
Программу используют живые люди. Они ошибаются, шутят и проверяют её на
прочность. Будь к этому готов.</div>

---

<!-- kicker: Защита -->

# Проверяй данные перед использованием

Главный приём ты уже знаешь — это `если`:

```eos
метод Скрипт()
    пер Возраст = Консоль.СчитатьЧисло("Возраст: ")
    если Возраст < 0 тогда
        Консоль.Записать("Возраст не может быть отрицательным")
    иначе
        Консоль.Записать("Тебе $Возраст лет")
    ;
;
```

---

<!-- kicker: Классика -->

# Деление на ноль

```eos
метод Делить(А: Число, Б: Число)
    если Б = 0 тогда
        Консоль.Записать("На ноль делить нельзя!")
    иначе
        Консоль.Записать("Результат: " + (А / Б))
    ;
;
```

<div class="callout tip"><span class="lead">Правило</span>
Проверку <code>Б = 0</code> ставь <strong>до</strong> деления. Защита всегда
идёт раньше опасного действия.</div>

<!-- kicker: Диапазон -->

# Проверяем, что число «в рамках»

```eos
метод Скрипт()
    пер Оценка = Консоль.СчитатьЧисло("Оценка (2-5): ")
    если Оценка >= 2 и Оценка <= 5 тогда
        Консоль.Записать("Принято: $Оценка")
    иначе
        Консоль.Записать("Так нельзя — нужно от 2 до 5")
    ;
;
```

---

<!-- kicker: Метод-страж -->

# Проверка как отдельный метод

```eos
метод Корректный(Оценка: Число): Булево
    возврат Оценка >= 2 и Оценка <= 5
;

метод Скрипт()
    пер О = Консоль.СчитатьЧисло("Оценка: ")
    если Корректный(О) тогда
        Консоль.Записать("Ок")
    иначе
        Консоль.Записать("Ошибка ввода")
    ;
;
```

Метод, возвращающий `Булево`, — удобный «страж» на входе.

# Что выведет программа при вводе `0`?

```eos
метод Скрипт()
    пер N = Консоль.СчитатьЧисло("Число: ")
    если N > 0 тогда
        Консоль.Записать("Положительное")
    иначеесли N < 0 тогда
        Консоль.Записать("Отрицательное")
    иначе
        Консоль.Записать("Это ноль")
    ;
;
```

# Есть и специальный механизм

В языке есть конструкция **`попытка`** — она ловит ошибки, которые трудно
предусмотреть заранее. Идея такая:

```eos
попытка
    // опасное действие
исключение
    // что делать, если случилась ошибка
;
```

<div class="callout warn"><span class="lead">Проверь в среде</span>
Точную запись <code>попытка/исключение</code> сверь с автодополнением своей
версии 1С:Элемент. А пока наш главный инструмент — проверки через
<code>если</code>.</div>

# Слабо защитить калькулятор?

Возьми метод `Делить(А, Б)` и добавь защиту: при делении на ноль —
сообщение, иначе — результат. Проверь на `10 / 2` и на `10 / 0`.

```out
10 / 2 = 5
10 / 0 -> На ноль делить нельзя!
```

<div class="callout"><span class="lead">Подсказка</span>
Это ровно тот приём со слайда «Деление на ноль».</div>

# Что мы узнали

- пользователь может ввести что угодно — проверяй данные;
- `если` — главный инструмент защиты;
- частые проверки: ноль, отрицательное, выход за диапазон;
- метод, возвращающий `Булево`, — удобный «страж»;
- для трудных случаев есть `попытка` (сверь запись со средой).
