# Урок 15. Решения (для преподавателя) — Когда что-то идёт не так

Цель урока: ученик защищает программу проверками (`если`) перед опасными
действиями: деление на ноль, отрицательные значения, выход за диапазон;
использует метод, возвращающий `Булево`, как «страж» ввода.

> Про `попытка/исключение`: в презентации показана как концепция. Точную
> запись сверьте с автодополнением среды. Основной инструмент урока —
> проверки через `если` (работают везде одинаково).

---

## Классная работа

**З1 (не отрицательный).**
```
если Возраст < 0 тогда
    Консоль.Записать("Так не бывает")
иначе
    Консоль.Записать("Ок")
;
```

**З2 (деление с защитой).**
```
если Б = 0 тогда
    Консоль.Записать("На ноль делить нельзя!")
иначе
    Консоль.Записать("Результат: " + (А / Б))
;
```

**З3 (оценка в рамках).** `если Оценка >= 2 и Оценка <= 5 тогда ... иначе ...`.

**З4 (метод-страж).**
```
метод Корректный(Оценка: Число): Булево
    возврат Оценка >= 2 и Оценка <= 5
;
метод Скрипт()
    пер О = Консоль.СчитатьЧисло("Оценка: ")
    если Корректный(О) тогда
        Консоль.Записать("Ок")
    иначе
        Консоль.Записать("Ошибка ввода")
    ;
;
```

**З5 (ввод 0).** Сработает ветка `иначе` → **`Ноль`**.

**З6 (безопасный калькулятор).**
```
метод Делить(А: Число, Б: Число)
    если Б = 0 тогда
        Консоль.Записать("На ноль делить нельзя!")
    иначе
        Консоль.Записать("Результат: " + (А / Б))
    ;
;
метод Скрипт()
    Делить(10, 2)    // 5
    Делить(10, 0)    // сообщение про ноль
;
```

---

## Домашняя работа — ответы

**Часть А.** А4 → при `5` сработает `иначе` → **`маленькое`**.

**Часть Б.**
- Б1 — диапазон через `и`.
- Б2 — `Корректный(Возраст): Булево` → `Возраст >= 0 и Возраст <= 120`.
- Б3 — цепочка `если/иначеесли` + финальное `иначе`.
- Б4 — проверка `Количество = 0` до деления.

**Часть В.**
- В1 — калькулятор с веткой проверки нуля (как в уроке 6, теперь оформлен
  методом).
- В2 — цикл из 3 попыток + счётчик; верный пароль завершает (довести цикл
  до конца, перестав менять результат — полноценный выход будет позже).
- В3 — три независимые проверки, каждая со своим сообщением.

---

## Типичные ошибки

- Делят/используют данные **до** проверки.
- Пишут диапазон как `2 <= x <= 5` вместо `x >= 2 и x <= 5`.
- Метод-страж возвращает `Булево`, но его пытаются «вывести» как число —
  он используется в `если`.
