# Карманный <span class="accent">помощник</span>

## Собираем программу из методов

Меню, выбор действия и расчёты — всё аккуратно разложено по методам.

---

<!-- kicker: Арсенал -->

# Что мы умеем после модуля 3

- создавать свои методы;
- передавать в них данные (параметры);
- возвращать ответ (`возврат`);
- собирать большую задачу из маленьких методов;
- защищать программу проверками.

Соберём из этого **помощника-калькулятор** с меню.

---

<!-- kicker: Задача -->

# Что должен уметь помощник

1. показать меню действий;
2. спросить, что посчитать;
3. спросить два числа;
4. посчитать нужным методом;
5. красиво вывести результат.

Каждое действие — **отдельный метод**.

---

<!-- kicker: Шаг 1 -->

# Методы-расчётчики

```eos
метод Площадь(А: Число, Б: Число): Число
    возврат А * Б
;

метод Среднее(А: Число, Б: Число): Число
    возврат (А + Б) / 2
;

метод Максимум(А: Число, Б: Число): Число
    если А > Б тогда
        возврат А
    иначе
        возврат Б
    ;
;
```

---

<!-- kicker: Шаг 2 -->

# Метод для меню

```eos
метод ПоказатьМеню()
    Консоль.Записать("=== Помощник ===")
    Консоль.Записать("1 — площадь")
    Консоль.Записать("2 — среднее")
    Консоль.Записать("3 — максимум")
;
```

Меню — тоже дело, и у него свой метод. `Скрипт` станет коротким и понятным.

---

<!-- kicker: Шаг 3 -->

# Собираем `Скрипт`

```eos
метод Скрипт()
    ПоказатьМеню()
    пер Выбор = Консоль.СчитатьЧисло("Действие: ")
    пер А = Консоль.СчитатьЧисло("Число А: ")
    пер Б = Консоль.СчитатьЧисло("Число Б: ")
    если Выбор = 1 тогда
        Консоль.Записать("Площадь: " + Площадь(А, Б))
    иначеесли Выбор = 2 тогда
        Консоль.Записать("Среднее: " + Среднее(А, Б))
    иначеесли Выбор = 3 тогда
        Консоль.Записать("Максимум: " + Максимум(А, Б))
    иначе
        Консоль.Записать("Нет такого действия")
    ;
;
```

---

<!-- kicker: Как читается -->

# `Скрипт` читается как план

<div class="callout tip"><span class="lead">Красота декомпозиции</span>
Покажи меню → спроси выбор → спроси числа → посчитай нужным методом.
Каждая строка <code>Скрипт</code> — это понятный шаг, а детали спрятаны
внутри методов.</div>

<!-- kicker: Тест -->

# Проверяем все ветки

```out
=== Помощник ===
1 — площадь
2 — среднее
3 — максимум
Действие: 1
Число А: 3
Число Б: 4
Площадь: 12
```

И обязательно проверь «неизвестное действие» — введи `9`.

---

<!-- kicker: Прокачай -->

# Как сделать круче

- добавить действие «сумма» или «разность»;
- защитить среднее и деление от нуля;
- повторять меню в цикле, пока не введут `0` (это циклы из модуля 2);
- добавить метод `Корректный(Выбор)` — страж ввода.
