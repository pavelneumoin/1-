# Урок 16. Решения (для преподавателя) — Проект «Карманный помощник»

Цель: ученик самостоятельно собирает программу из методов (расчётчики +
меню + выбор), используя весь модуль 3. Проектный урок — ценится
декомпозиция и доведение до рабочего состояния.

---

## Полная версия

```eos
метод Площадь(А: Число, Б: Число): Число
    возврат А * Б
;
метод Среднее(А: Число, Б: Число): Число
    возврат (А + Б) / 2
;
метод Максимум(А: Число, Б: Число): Число
    если А > Б тогда
        возврат А
    иначе
        возврат Б
    ;
;
метод ПоказатьМеню()
    Консоль.Записать("=== Помощник ===")
    Консоль.Записать("1 — площадь")
    Консоль.Записать("2 — среднее")
    Консоль.Записать("3 — максимум")
;
метод Скрипт()
    ПоказатьМеню()
    пер Выбор = Консоль.СчитатьЧисло("Действие: ")
    пер А = Консоль.СчитатьЧисло("Число А: ")
    пер Б = Консоль.СчитатьЧисло("Число Б: ")
    если Выбор = 1 тогда
        Консоль.Записать("Площадь: " + Площадь(А, Б))
    иначеесли Выбор = 2 тогда
        Консоль.Записать("Среднее: " + Среднее(А, Б))
    иначеесли Выбор = 3 тогда
        Консоль.Записать("Максимум: " + Максимум(А, Б))
    иначе
        Консоль.Записать("Нет такого действия")
    ;
;
```

Тестировать: каждое действие + ввод `9` (неизвестное действие).

---

## Улучшения (часть 4)

- **A (новые действия):** методы `Сумма`/`Разность` + пункты меню 4/5.
- **B (цикл):** обернуть меню и расчёт в `пока Выбор <> 0 цикл ... ;`,
  читая выбор внутри цикла.
- **C (страж):** `метод Корректный(В: Число): Булево возврат В >= 1 и В <= 3 ;`.
- **D (имя):** спросить имя строкой, использовать в выводе через `$Имя`.

## Домашняя работа — ответы (ориентиры)

- **Часть А** — полная версия выше + подпись действия.
- **Б1** — `Сумма`/`Разность` тривиальны (`возврат А + Б` / `А - Б`).
- **Б2** — страж `Корректный` от 1 до 5.
- **Б3** — `Делить(А, Б)` с проверкой `Б = 0`.
- **Б4** — три метода, три результата.
- **Часть В** — оцениваем целостность: программа собрана из методов,
  каждый делает одно дело, `Скрипт` читается как план.

## Типичные трудности

- Считают прямо в `Скрипт`, не вынося в методы — напомнить цель модуля.
- Забывают `возврат` в методах-расчётчиках.
- Длинная цепочка `иначеесли` без финального `иначе` — нет реакции на
  неизвестный выбор.
- При добавлении цикла забывают читать `Выбор` внутри цикла → бесконечный
  цикл (привет, урок 7).
