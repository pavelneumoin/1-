<!-- kicker: Урок 19 -->

# Считаем <span class="accent">поток данных</span>

## Алгоритмы: подсчёт и сумма

Программа обрабатывает не одно число, а целую серию — и подводит итоги.

---

<!-- kicker: Идея -->

# Серия чисел, а не одно

Раньше мы считали одно-два числа. А что, если их **много** — и заранее
не знаешь сколько?

Приём: читаем числа **в цикле** и на ходу копим итог — сумму, количество,
среднее.

---

<!-- kicker: Стоп-число -->

# Читаем, пока не введут «стоп»

Договоримся: ввод `0` означает «хватит». Это **стоп-число** (сигнал конца).

```eos
метод Скрипт()
    пер Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
    пока Число <> 0 цикл
        Консоль.Записать("Принял: $Число")
        Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
    ;
    Консоль.Записать("Готово")
;
```

---

<!-- kicker: Разбор -->

# Как устроен такой цикл

1. читаем **первое** число до цикла;
2. `пока Число <> 0` — повторяем тело;
3. в конце тела читаем **следующее** число;
4. ввели `0` — условие ложно, цикл закончился.

<div class="callout warn"><span class="lead">Не забудь</span>
Читать новое число внутри цикла обязательно — иначе бесконечный цикл.</div>

---

<!-- kicker: Сумма -->

# Копим сумму серии

```eos
метод Скрипт()
    пер Сумма = 0
    пер Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
    пока Число <> 0 цикл
        Сумма = Сумма + Число
        Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
    ;
    Консоль.Записать("Сумма: $Сумма")
;
```

«Копилка» `Сумма = 0` — до цикла, пополняем внутри.

---

<!-- kicker: Количество -->

# Считаем, сколько ввели

Заводим счётчик и увеличиваем его на каждом числе:

```eos
пер Количество = 0
пер Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
пока Число <> 0 цикл
    Количество = Количество + 1
    Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
;
Консоль.Записать("Ввели чисел: $Количество")
```

---

<!-- kicker: Среднее -->

# Сумма и количество = среднее

Если копить и сумму, и количество — получим среднее:

```eos
если Количество > 0 тогда
    Консоль.Записать("Среднее: " + (Сумма / Количество))
иначе
    Консоль.Записать("Не ввели ни одного числа")
;
```

<div class="callout tip"><span class="lead">Защита</span>
Делить на количество можно, только если оно не ноль. Привет, урок 15.</div>

---

<!-- kicker: Подсчёт с условием -->

# Считаем не все, а нужные

Например, сколько среди чисел положительных:

```eos
если Число > 0 тогда
    Положительных = Положительных + 1
;
```

Этот `если` ставим **внутри** цикла — проверяем каждое число.

---

<!-- kicker: Угадай -->
<!-- class: content tight -->

# Что выведет программа?

Ввели по очереди: `4`, `6`, `0`.

```eos
пер С = 0
пер К = 0
пер X = Консоль.СчитатьЧисло("")
пока X <> 0 цикл
    С = С + X
    К = К + 1
    X = Консоль.СчитатьЧисло("")
;
Консоль.Записать("$С и $К")
;
```

<div class="callout quiz"><span class="lead">Считай по кругам</span>
Что окажется в <code>С</code> (сумма) и <code>К</code> (количество)?</div>

---

<!-- kicker: Челлендж -->
<!-- class: content -->

# Слабо посчитать положительные?

Читай числа до `0`. В конце выведи, **сколько** из них было больше нуля.

```out
Число (0 — стоп): 5
Число (0 — стоп): -2
Число (0 — стоп): 8
Число (0 — стоп): 0
Положительных: 2
```

<div class="callout"><span class="lead">Подсказка</span>
Счётчик <code>Положительных</code> увеличивай только в ветке
<code>если Число &gt; 0</code>.</div>

---

<!-- kicker: Итоги -->

# Что мы узнали

- серию чисел читаем в цикле со **стоп-числом**;
- первое число — до цикла, следующее — в конце тела;
- сумму и количество копим в переменных;
- среднее = сумма / количество (защищай от деления на ноль);
- подсчёт с условием — `если` внутри цикла.
