# Урок 19. Решения (для преподавателя) — Подсчёт и сумма

Цель урока: ученик читает серию чисел в цикле со стоп-значением, копит
сумму и количество, считает среднее (с защитой), ведёт подсчёт по условию.

---

## Классная работа

**З1 (эхо до стопа).**
```
метод Скрипт()
    пер Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
    пока Число <> 0 цикл
        Консоль.Записать("Принял: $Число")
        Число = Консоль.СчитатьЧисло("Число (0 — стоп): ")
    ;
;
```

**З2 (сумма).** Завести `Сумма = 0`, в теле `Сумма = Сумма + Число`.

**З3 (количество).** Завести `Количество = 0`, в теле `+1`.

**З4 (среднее).**
```
если Количество > 0 тогда
    Консоль.Записать("Среднее: " + (Сумма / Количество))
иначе
    Консоль.Записать("Чисел не было")
;
```

**З5 (что выведет).** Сумма `4 + 6 = 10`, количество `2`. Ответ: **С = 10, К = 2**.

**З6 (положительные).** Внутри цикла: `если Число > 0 тогда Полож = Полож + 1 ;`.

**З7 (сумма чётных).** Внутри цикла: `если Число % 2 = 0 тогда Сумма = Сумма + Число ;`.
(Если `%` недоступен — найти аналог в среде.)

## Типичные ошибки

- Забывают читать следующее число внутри цикла → бесконечный цикл.
- Объявляют `Сумма`/`Количество` внутри цикла — обнуляются каждый круг.
- Делят на количество без проверки на ноль.
- Читают первое число только внутри цикла и теряют его в условии.
