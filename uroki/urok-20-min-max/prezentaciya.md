# Найти <span class="accent">лучшего</span>

## Алгоритмы: минимум и максимум

Как программа находит самое большое и самое маленькое в серии чисел.

---

<!-- kicker: Задача -->

# Кто рекордсмен?

Ввели рост пятерых друзей. Кто самый высокий? А самый низкий?

Хранить все числа не обязательно — можно найти максимум **на ходу**,
пока читаем серию.

---

<!-- kicker: Идея -->

# Принцип «текущий чемпион»

- запоминаем первое число как **текущий максимум**;
- каждое следующее сравниваем с чемпионом;
- если новое больше — оно становится новым чемпионом.

В конце в «чемпионе» лежит самое большое число.

---

<!-- kicker: Максимум -->

# Находим максимум

```eos
метод Скрипт()
    пер Макс = Консоль.СчитатьЧисло("Сколько чисел вводить? ")
    пер N = Макс
    Макс = Консоль.СчитатьЧисло("Число 1: ")
    для i = 2 по N цикл
        пер X = Консоль.СчитатьЧисло("Число: ")
        если X > Макс тогда
            Макс = X
        ;
    ;
    Консоль.Записать("Максимум: $Макс")
;
```

Первое число — стартовый чемпион, остальные сравниваем в цикле.

---

<!-- kicker: Минимум -->

# Минимум — всё наоборот

Тот же приём, только знак сравнения меняем на `<`:

```eos
если X < Мин тогда
    Мин = X
;
```

<div class="callout tip"><span class="lead">Симметрия</span>
Максимум и минимум ищут одинаково. Разница — один знак: <code>&gt;</code>
против <code>&lt;</code>.</div>

---

<!-- kicker: Важно -->

# Почему первое число — отдельно

Нельзя начать максимум с нуля: вдруг все числа отрицательные?

```eos
// плохо: если все числа < 0, ответ останется 0
пер Макс = 0

// хорошо: стартуем с реального первого числа
пер Макс = Консоль.СчитатьЧисло("Число 1: ")
```

<div class="callout warn"><span class="lead">Ловушка</span>
Стартовое значение чемпиона — это <strong>первый элемент</strong>,
а не ноль.</div>

---

<!-- kicker: Вместе -->

# Максимум и минимум сразу

Можно искать оба за один проход — две переменные:

```eos
пер Макс = X1
пер Мин = X1
// далее в цикле:
если X > Макс тогда Макс = X ;
если X < Мин тогда Мин = X ;
```

Оба «чемпиона» стартуют с первого числа.

# Каким будет максимум?

Числа по очереди: `3`, `9`, `2`, `7`.

```eos
пер Макс = 3
// затем сравниваем 9, 2, 7:
если X > Макс тогда
    Макс = X
;
```

Когда «чемпион» меняется, а когда остаётся прежним?</div>

<!-- class: content -->

# Слабо найти самого высокого?

Спроси рост 4 друзей и выведи самый большой рост.

```out
Рост 1: 150
Рост 2: 162
Рост 3: 158
Рост 4: 171
Самый высокий: 171
```

<div class="callout"><span class="lead">Подсказка</span>
Первый рост — стартовый максимум, остальные три сравнивай в цикле
<code>для i = 2 по 4</code>.</div>

---

<!-- kicker: Итоги -->

# Что мы узнали

- максимум/минимум ищем приёмом «текущий чемпион»;
- стартуем чемпиона **первым** числом, не нулём;
- каждое следующее число сравниваем и при необходимости обновляем;
- максимум и минимум различаются одним знаком сравнения;
- оба можно найти за один проход.
