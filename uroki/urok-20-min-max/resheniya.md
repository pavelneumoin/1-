# Урок 20. Решения (для преподавателя) — Минимум и максимум

Цель урока: ученик находит минимум/максимум серии приёмом «текущий
чемпион», понимает, почему старт — первый элемент, а не ноль.

---

## Классная работа

**З1 (макс из трёх).** Через сравнения `если/иначеесли` либо: старт первым,
сравнить со вторым и третьим.

**З2 (макс из N).**
```
метод Скрипт()
    пер N = Консоль.СчитатьЧисло("Сколько чисел? ")
    пер Макс = Консоль.СчитатьЧисло("Число 1: ")
    для i = 2 по N цикл
        пер X = Консоль.СчитатьЧисло("Число: ")
        если X > Макс тогда
            Макс = X
        ;
    ;
    Консоль.Записать("Максимум: $Макс")
;
```

**З3 (мин из N).** То же, знак `<`, переменная `Мин`.

**З4 (трассировка).** Старт 3 → 9 → 9 → 9. Ответ: 3, 9, 9, 9.

**З5 (ошибка).** Старт `Макс = 0` неверен: если все числа отрицательные,
условие `X > 0` ни разу не сработает, ответ останется `0`. Исправление —
стартовать первым прочитанным числом, а цикл начинать со второго.

**З6 (мин и макс сразу).**
```
пер Перв = Консоль.СчитатьЧисло("Число 1: ")
пер Мин = Перв
пер Макс = Перв
для i = 2 по N цикл
    пер X = Консоль.СчитатьЧисло("Число: ")
    если X > Макс тогда Макс = X ;
    если X < Мин тогда Мин = X ;
;
```

**З7 (размах).** Найти Мин и Макс (как в З6), вывести `Макс - Мин`.

---

## Домашняя работа — ответы

**Часть А.** А4 → 8.

**Часть Б.** Б1/Б2 — макс/мин серии. Б3 — макс очков. Б4 — мин цены.

**Часть В.** В1 — два чемпиона за проход. В2 — макс, мин и `Макс - Мин`.
В3 — и максимальный, и минимальный рост.

---

## Типичные ошибки

- Старт чемпиона нулём вместо первого элемента (см. З5) — ключевая ошибка.
- Начинают цикл с `i = 1`, повторно читая первое число (сбой счёта) —
  при старте первым элементом цикл идёт с `i = 2`.
- Путают знак сравнения для мин/макс.
