# Анализатор <span class="accent">чисел</span>

## Собираем алгоритмы в одну программу

Программа примет серию чисел и выдаст полный отчёт: сколько, сумма,
среднее, минимум и максимум.

---

<!-- kicker: Арсенал -->

# Что мы умеем

- читать серию чисел в цикле;
- копить сумму и количество;
- считать среднее;
- находить минимум и максимум;
- защищаться проверками.

Соберём из этого настоящий **анализатор**.

---

<!-- kicker: Задача -->

# Что должен показать отчёт

По введённой серии чисел:

1. сколько чисел ввели;
2. их сумму;
3. среднее;
4. минимум;
5. максимум.

Всё — за **один проход**, без хранения чисел.

---

<!-- kicker: Шаг 1 -->

# Спросим, сколько чисел

```eos
метод Скрипт()
    пер N = Консоль.СчитатьЧисло("Сколько чисел? ")
    если N < 1 тогда
        Консоль.Записать("Нужно хотя бы одно число")
    иначе
        // основная часть — дальше
    ;
;
```

Сначала защита: если чисел меньше одного — анализировать нечего.

---

<!-- kicker: Шаг 2 -->

# Первое число — стартовое

```eos
пер Первое = Консоль.СчитатьЧисло("Число 1: ")
пер Сумма = Первое
пер Мин = Первое
пер Макс = Первое
```

Первое число задаёт старт всем «копилкам»: сумма равна ему, а он же —
пока и минимум, и максимум.

---

<!-- kicker: Шаг 3 -->

# Остальные числа — в цикле

```eos
для i = 2 по N цикл
    пер X = Консоль.СчитатьЧисло("Число: ")
    Сумма = Сумма + X
    если X > Макс тогда
        Макс = X
    ;
    если X < Мин тогда
        Мин = X
    ;
;
```

За один проход обновляем сумму, максимум и минимум.

---

<!-- kicker: Шаг 4 -->

# Печатаем отчёт

```eos
Консоль.Записать("Чисел: $N")
Консоль.Записать("Сумма: $Сумма")
Консоль.Записать("Среднее: " + (Сумма / N))
Консоль.Записать("Минимум: $Мин")
Консоль.Записать("Максимум: $Макс")
```

Количество известно (`N`), значит, среднее считаем без боязни делить на ноль.

---

# Собираем программу

```eos
метод Скрипт()
    пер N = Консоль.СчитатьЧисло("Сколько чисел? ")
    если N < 1 тогда
        Консоль.Записать("Нужно хотя бы одно число")
    иначе
        пер X = Консоль.СчитатьЧисло("Число 1: ")
        пер Сумма = X
        пер Мин = X
        пер Макс = X
        для i = 2 по N цикл
            X = Консоль.СчитатьЧисло("Число: ")
            Сумма = Сумма + X
            если X > Макс тогда Макс = X ;
            если X < Мин тогда Мин = X ;
        ;
        Консоль.Записать("Сумма: $Сумма")
        Консоль.Записать("Среднее: " + (Сумма / N))
        Консоль.Записать("Мин: $Мин, Макс: $Макс")
    ;
;
```

<!-- kicker: Прокачай -->

# Как сделать круче

- считать отдельно количество положительных и отрицательных;
- вынести поиск максимума в метод `Максимум`;
- читать числа до стоп-значения `0`, а не по количеству;
- найти размах: `Макс - Мин`.
