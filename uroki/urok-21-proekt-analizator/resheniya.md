# Урок 21. Решения (для преподавателя) — Проект «Анализатор чисел»

Цель: ученик собирает полноценную обработку серии данных за один проход
(количество, сумма, среднее, минимум, максимум) — без массивов, только на
циклах, условиях и переменных.

---

## Полная версия

```eos
метод Скрипт()
    пер N = Консоль.СчитатьЧисло("Сколько чисел? ")
    если N < 1 тогда
        Консоль.Записать("Нужно хотя бы одно число")
    иначе
        пер X = Консоль.СчитатьЧисло("Число 1: ")
        пер Сумма = X
        пер Мин = X
        пер Макс = X
        для i = 2 по N цикл
            X = Консоль.СчитатьЧисло("Число: ")
            Сумма = Сумма + X
            если X > Макс тогда Макс = X ;
            если X < Мин тогда Мин = X ;
        ;
        Консоль.Записать("Чисел: $N")
        Консоль.Записать("Сумма: $Сумма")
        Консоль.Записать("Среднее: " + (Сумма / N))
        Консоль.Записать("Мин: $Мин")
        Консоль.Записать("Макс: $Макс")
    ;
;
```

Тестировать: одно число (мин = макс = среднее), отрицательные числа,
`N = 0` (сработает защита).

---

## Улучшения (часть 4)

- **A (размах):** `Консоль.Записать("Размах: " + (Макс - Мин))`.
- **B (положительные):** счётчик `если X > 0 тогда Полож = Полож + 1 ;`
  (не забыть проверить и первое число).
- **C (метод):** `метод Среднее(С: Число, К: Число): Число возврат С / К ;`.
- **D (до стопа):** заменить счётный цикл на `пока X <> 0`, читая число в
  конце тела; количество считать счётчиком.

---

## Домашняя работа — ответы (ориентиры)

- **Часть А** — полная версия выше + защита `N < 1`.
- **Б1** — размах. **Б2** — счётчик положительных. **Б3** — метод
  `Среднее`. **Б4** — анализатор оценок с проверкой диапазона 2–5.
- **Часть В** — оцениваем корректность алгоритма и обработку краёв
  (одно число, все одинаковые, отрицательные). В3 честно сложен без
  массивов — засчитываем разумный подход (двойной ввод или сравнение
  по ходу), это хороший момент показать, зачем вообще нужны массивы.

---

## Мостик к массивам

Если ученик спросит «а как сравнить со средним, не вводя числа дважды?» —
это идеальный момент сказать: для таких задач нужны **массивы** (хранение
всей серии). Их разберём, когда подключим работу с коллекциями.

---

## Типичные трудности

- Старт `Мин`/`Макс` нулём вместо первого числа.
- Объявляют `Сумма`/`Мин`/`Макс` внутри цикла.
- Забывают учесть первое число в подсчёте положительных.
- Делят на `N` без защиты (здесь `N >= 1` гарантировано проверкой — хорошо).
